# RoverD: custom-marker gate navigation

Shared Group D two-wheel rover project: Raspberry Pi vision identifies paired 4×4 markers, smooths gate position and emits steering letters; Raspberry Pi Pico C++ firmware maps those letters into slew-limited differential motor PWM with a UART watchdog.

![Synthetic marker-to-steering demo](samples/gate-demo.png)

## Safe offline demonstration

Python 3.10+, NumPy and OpenCV are sufficient. The demo imports no GPIO, serial or camera modules and opens no hardware.

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r final_navigation/vision/requirements.txt
python final_navigation/vision/offline_demo.py --output demo-output
PYTHON=python ./tests/run-offline.sh
```

The demo generates both marker cards, runs the actual contour/pattern/gate/steering pipeline, and writes `gate-demo.png` and `result.json`. The bundled generated output reports two markers, a center near x=640, command `go`, and letter `M` (the contour center is just left of the M/N boundary). It contains no camera footage.

The test script runs six Python tests and four native C++ firmware scenarios. Its tiny fake Pico SDK supplies only UART, clock and output boundaries; parser, timeout and steering logic come directly from the production firmware header. It validates software behavior without energizing motors.

## Build Pico firmware

Install an official Raspberry Pi Pico SDK and ARM embedded compiler separately, then use their locations:

```bash
cmake -S final_navigation/firmware -B build-pico   -DPICO_SDK_PATH=/path/to/pico-sdk   -DPICO_TOOLCHAIN_PATH=/path/to/arm-toolchain
cmake --build build-pico --parallel
```

This generates `build-pico/rover_move.uf2` for the default RP2040 Pico board. No firmware was flashed during verification. The copy fixes rejection of entire overlong UART lines, the time-zero receive/timeout edge case, equal wheel output in the configured straight band, and SDK path selection with `-D`.

## Physical runtime

`final_navigation/vision/main.py` is the Pi camera/GPIO/UART runtime. Running it can move the rover. It additionally requires Raspberry Pi OS packages providing `picamera2`, `RPi.GPIO` and `serial` (`pyserial`), and working libcamera support. Use distro packages for Pi camera/GPIO integration; the offline requirements deliberately cover only desktop execution. Review pins, UART selection, power, motor polarity and mechanical calibration before using hardware. `test_visualise_laptop.py` is an optional live-camera tool, separate from the offline demo.

The firmware receives one ASCII `A-Z`, `a-z` or `?` followed by LF or CR. The letter selects steering; case currently has no effect on PWM. `?` requests a slew-limited stop; the 300 ms link timeout invokes an immediate zero output after expiry. Invalid packets do not refresh that timeout.

# Pico firmware

See the repository [README](../../README.md) for SDK configuration and tests. The default board is RP2040 Pico. `rover_move.cpp` implements boot, waiting, active drive and failsafe states; `rover_move.hpp` contains parser, steering and hardware primitives.

UART0 RX is GP17, TX GP16, at 9600 baud. M1 DIR/PWM is GP1/GP0; M2 DIR/PWM GP10/GP11. The control loop runs every 40 ms, the slew step is 8, base demand 120/255, the K-P/k-p band is straight, and timeout is greater than 300 ms since the last valid line. Validate these settings against the actual rover. Native tests do not prove wiring, power, motor direction, stopping distance or mechanical safety.

#include "rover_move.hpp"

int main() {
    MachineContext ctx;
    DriveState     state = DriveState::BOOT;

    while (true) {
        // ~25 Hz loop cadence; matches the Pi TX rate
        sleep_ms(40);

        bool got_letter = false;
        if (state != DriveState::BOOT) {
            got_letter = updateContextFromSerial(ctx);
        }

        switch (state) {

            // ---------------------------------------------------
            case DriveState::BOOT:
            // ---------------------------------------------------
                initHardware(ctx);
                state = DriveState::WAIT_LINK;
                break;

            // ---------------------------------------------------
            case DriveState::WAIT_LINK:
            // ---------------------------------------------------
                // Motors already zeroed by initHardware.
                // Advance as soon as the first valid letter arrives.
                if (got_letter) {
                    state = DriveState::ACTIVE_DRIVE;
                }
                break;

            // ---------------------------------------------------
            case DriveState::ACTIVE_DRIVE:
            // ---------------------------------------------------
                driveFromLetter(ctx, ctx.last_letter);
                if (isLinkTimedOut(ctx)) {
                    stopMotors(ctx);
                    state = DriveState::FAILSAFE_STOP;
                }
                break;

            // ---------------------------------------------------
            case DriveState::FAILSAFE_STOP:
            // ---------------------------------------------------
                // Motors are stopped.
                // Return to ACTIVE_DRIVE the moment a fresh valid
                // letter is received on the UART.
                if (got_letter) {
                    state = DriveState::ACTIVE_DRIVE;
                }
                break;
        }
    }

    return 0;
}

#ifndef ROVER_MOVE_H
#define ROVER_MOVE_H

#include <cstdlib>
#include <cstring>
#include <cmath>
#include "pico/stdlib.h"
#include "hardware/uart.h"
#include "hardware/pwm.h"
#include "hardware/gpio.h"
#include "hardware/clocks.h"


// ============================================================
//  Drive FSM states
//   BOOT          – one-shot hardware init
//   WAIT_LINK     – motors off, waiting for the first valid letter
//   ACTIVE_DRIVE  – letter → PWM every cycle
//   FAILSAFE_STOP – timeout / corrupt stream → motors off until fresh letter
// ============================================================
enum class DriveState {
    BOOT,
    WAIT_LINK,
    ACTIVE_DRIVE,
    FAILSAFE_STOP
};

// ============================================================
//  Runtime context  (all mutable state in one struct)
// ============================================================
struct MachineContext {
    // Motor pins: M1 → GP1  (DIR) / GP0  (PWM)
    //             M2 → GP10 (DIR) / GP11 (PWM)
    // UART0 RX → GP17 (Pi GPIO14 TX), UART0 TX → GP16
    const uint M1_DIR_PIN = 1;
    const uint M1_PWM_PIN = 0;
    const uint M2_DIR_PIN = 10;
    const uint M2_PWM_PIN = 11;

    // PWM hardware
    const int  MAX_PWM  = 255;
    uint16_t   pwm_wrap = 0;

    // UART receive buffer (newline-delimited protocol)
    char     serial_buf[64] = {};
    int      buf_index      = 0;
    bool     discarding_line = false;
    bool     has_received = false;
    uint32_t last_rx_ms     = 0;   // ms timestamp of last valid letter

    // Current drive values
    char last_letter = '?';
    int  curr_l      = 0;          // slew-limited left  PWM output
    int  curr_r      = 0;          // slew-limited right PWM output

    // Safety timeout: enter FAILSAFE_STOP if no valid letter for this long
    const uint32_t RX_TIMEOUT_MS = 300;

};

// ============================================================
//  Motor primitives
// ============================================================
inline void setMotorSpeeds(MachineContext& ctx, int pwm1, int pwm2) {
    // Motor 1
    gpio_put(ctx.M1_DIR_PIN, pwm1 >= 0 ? 1 : 0);
    int sp1 = std::abs(pwm1);
    if (sp1 > ctx.MAX_PWM) sp1 = ctx.MAX_PWM;
    pwm_set_gpio_level(ctx.M1_PWM_PIN,
                       (uint16_t)((sp1 * ctx.pwm_wrap) / ctx.MAX_PWM));

    // Motor 2
    gpio_put(ctx.M2_DIR_PIN, pwm2 >= 0 ? 1 : 0);
    int sp2 = std::abs(pwm2);
    if (sp2 > ctx.MAX_PWM) sp2 = ctx.MAX_PWM;
    pwm_set_gpio_level(ctx.M2_PWM_PIN,
                       (uint16_t)((sp2 * ctx.pwm_wrap) / ctx.MAX_PWM));
}

inline void stopMotors(MachineContext& ctx) {
    setMotorSpeeds(ctx, 0, 0);
    ctx.curr_l = 0;
    ctx.curr_r = 0;
}

// ============================================================
//  Hardware init  (called once in BOOT state)
// ============================================================
inline void initHardware(MachineContext& ctx) {
    stdio_init_all();

    // PWM at ~20 kHz
    uint32_t sys_clk = clock_get_hz(clk_sys);
    ctx.pwm_wrap     = (uint16_t)(sys_clk / 20000);

    // Motor 1: DIR = GP1, PWM = GP0
    gpio_init(ctx.M1_DIR_PIN);
    gpio_set_dir(ctx.M1_DIR_PIN, GPIO_OUT);
    gpio_set_function(ctx.M1_PWM_PIN, GPIO_FUNC_PWM);
    uint slice1 = pwm_gpio_to_slice_num(ctx.M1_PWM_PIN);
    pwm_set_wrap(slice1, ctx.pwm_wrap);
    pwm_set_enabled(slice1, true);

    // Motor 2: DIR = GP10, PWM = GP11
    gpio_init(ctx.M2_DIR_PIN);
    gpio_set_dir(ctx.M2_DIR_PIN, GPIO_OUT);
    gpio_set_function(ctx.M2_PWM_PIN, GPIO_FUNC_PWM);
    uint slice2 = pwm_gpio_to_slice_num(ctx.M2_PWM_PIN);
    pwm_set_wrap(slice2, ctx.pwm_wrap);
    pwm_set_enabled(slice2, true);

    stopMotors(ctx);

    // UART0 at 9600 baud: GP16 = TX (Pico → Pi), GP17 = RX (Pi → Pico)
    uart_init(uart0, 9600);
    gpio_set_function(16, GPIO_FUNC_UART);
    gpio_set_function(17, GPIO_FUNC_UART);
}


// ============================================================
//  Letter → motor speed mapping
//
//  Zone index 0-25 maps A=0 … Z=25 (or a=0 … z=25).
//  t in [-1, +1]: negative = left, positive = right.
//
//  Differential drive mixing (outer motor stays at BASE,
//  inner motor scales toward -BASE):
//    left  = BASE – clamp(t, 0, 1) × 2 × BASE
//    right = BASE + clamp(t,-1, 0) × 2 × BASE
//
//  BASE = 120. K-P/k-p form the straight-ahead deadband.
//  Only A/a and Z/z may reverse one wheel; intermediate zones
//  keep the inner motor at a minimum demand of 24.
//  '?' requests zero targets through the same slew limiter.
//
//  Slew-rate limit of 8 PWM units per call reduces jerk.
// ============================================================
inline void driveFromLetter(MachineContext& ctx, char c) {
    int target_l, target_r;

    int zone = -1;
    if      (c >= 'A' && c <= 'Z') zone = c - 'A';
    else if (c >= 'a' && c <= 'z') zone = c - 'a';

    if (zone < 0) {
        // '?' or any unrecognised character → soft stop via slew limiting
        target_l = 0;
        target_r = 0;
    } else {
        // Treat a wider center band as straight ahead so small CV jitter does
        // not keep nudging the rover left and right while it crosses a gate.
        if (zone >= 10 && zone <= 15) {
            zone = 12;
        }

        // Continuous differential drive mixing
        float t = zone == 12 ? 0.0f : (zone - 12.5f) / 12.5f;
        if (t < -1.0f) t = -1.0f;
        if (t >  1.0f) t =  1.0f;

        const float BASE = 120.0f;
        float t_pos = (t > 0.0f) ? t : 0.0f;
        float t_neg = (t < 0.0f) ? t : 0.0f;

        target_l = (int)(BASE - t_pos * 2.0f * BASE);
        target_r = (int)(BASE + t_neg * 2.0f * BASE);

        // Keep intermediate steering letters from turning into violent
        // spin-in-place commands. Only the extreme edge zones may reverse one wheel.
        const int MIN_INNER_PWM = 24;
        if (zone > 0 && zone < 25) {
            if (target_l < MIN_INNER_PWM) target_l = MIN_INNER_PWM;
            if (target_r < MIN_INNER_PWM) target_r = MIN_INNER_PWM;
        }

        // Clamp to motor range
        if (target_l >  ctx.MAX_PWM) target_l =  ctx.MAX_PWM;
        if (target_l < -ctx.MAX_PWM) target_l = -ctx.MAX_PWM;
        if (target_r >  ctx.MAX_PWM) target_r =  ctx.MAX_PWM;
        if (target_r < -ctx.MAX_PWM) target_r = -ctx.MAX_PWM;
    }

    // Slew-rate limit: smaller changes per cycle keep the two-wheel chassis calm.
    const int SLEW = 8;
    int dl = target_l - ctx.curr_l;
    int dr = target_r - ctx.curr_r;
    if (dl >  SLEW) dl =  SLEW;
    if (dl < -SLEW) dl = -SLEW;
    if (dr >  SLEW) dr =  SLEW;
    if (dr < -SLEW) dr = -SLEW;

    ctx.curr_l += dl;
    ctx.curr_r += dr;

    setMotorSpeeds(ctx, ctx.curr_l, ctx.curr_r);
}

// ============================================================
//  Serial line receiver
//
//  Protocol: one ASCII letter (or '?') followed by '\n'.
//  Malformed lines (wrong length, bad char, overlong) are
//  silently discarded.
//
//  Returns true and updates ctx.last_letter / ctx.last_rx_ms
//  when a valid letter is parsed from the stream.
// ============================================================
inline bool updateContextFromSerial(MachineContext& ctx) {
    bool got_letter = false;

    while (uart_is_readable(uart0)) {
        char c = uart_getc(uart0);

        if (c == '\n' || c == '\r') {
            if (ctx.discarding_line) {
                ctx.discarding_line = false;
                ctx.buf_index = 0;
                continue;
            }
            if (ctx.buf_index > 0) {
                ctx.serial_buf[ctx.buf_index] = '\0';
                char letter = ctx.serial_buf[0];

                // Valid: exactly one letter A-Z, a-z, or '?'
                bool valid_char = ((letter >= 'A' && letter <= 'Z') ||
                                   (letter >= 'a' && letter <= 'z') ||
                                   letter == '?');

                if (ctx.buf_index == 1 && valid_char) {
                    ctx.has_received = true;
                    ctx.last_letter = letter;
                    ctx.last_rx_ms  = to_ms_since_boot(get_absolute_time());
                    got_letter      = true;
                }
                // Silently drop malformed lines and reset buffer
                ctx.buf_index = 0;
                memset(ctx.serial_buf, 0, sizeof(ctx.serial_buf));
            }
        } else {
            if (ctx.discarding_line) continue;
            if (ctx.buf_index < 63) {
                ctx.serial_buf[ctx.buf_index++] = c;
            } else {
                // Discard through the delimiter; a suffix must never become a command.
                ctx.discarding_line = true;
                ctx.buf_index = 0;
                memset(ctx.serial_buf, 0, sizeof(ctx.serial_buf));
            }
        }
    }

    return got_letter;
}

// Returns true when the link has timed out (no valid letter within RX_TIMEOUT_MS).
// Safe before the first valid command, including a command received at time zero.
inline bool isLinkTimedOut(const MachineContext& ctx) {
    if (!ctx.has_received) return false;
    uint32_t now = to_ms_since_boot(get_absolute_time());
    return (now - ctx.last_rx_ms) > ctx.RX_TIMEOUT_MS;
}

#endif // ROVER_MOVE_H

def capture_grid_live():
    """Show live preview, press SPACE to capture, ESC to cancel."""
    cap = cv2.VideoCapture(0)
    if not cap.isOpened():
        print("ERROR: Cannot open camera")
        return None

    print("  Opening camera preview... Press SPACE to capture, ESC to cancel")

    captured_grid = None

    while True:
        ok, frame = cap.read()
        if not ok:
            break

        vis = frame.copy()
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        markers = find_squares(gray=gray)

        if markers:
            best = max(markers, key=lambda m: m['area'])
            corners = best['corners'].astype(int)

            # Draw green outline on detected square
            cv2.polylines(vis, [corners.reshape(-1, 1, 2)], True, (0, 255, 0), 2)

            # Show grid preview
            patch = warp_to_patch(frame, best['corners'])
            grid = extract_grid(patch)

            # Draw grid values on screen

                       cv2.FONT_HERSHEY_SIMPLEX, 0.5, (0, 255, 0), 1)

# custom_marker_finder.py - Robust detector for the project's custom 4x4 markers
#
# This keeps the old marker contract:
#   square contour -> perspective warp -> 4x4 grid -> left/right type
# but packages it as one detector stage and removes duplicate contour hits.

import cv2
import numpy as np

import config
from pattern_reader import extract_grid, rotate_grid_90, warp_to_patch
from square_finder import find_squares


DEFAULT_MAX_HAMMING = getattr(config, 'CUSTOM_MARKER_MAX_HAMMING', 2)
DEFAULT_DUPLICATE_CENTER_FRACTION = getattr(config, 'CUSTOM_MARKER_DUPLICATE_CENTER_FRACTION', 0.35)


def hamming_distance(a, b):
    return int(np.count_nonzero(np.asarray(a, dtype=int) != np.asarray(b, dtype=int)))


def classify_grid(grid, max_hamming=DEFAULT_MAX_HAMMING):
    """
    Match a read grid against configured patterns, trying all rotations.

    Returns:
        marker_type: 'left', 'right', or 'unknown'
        best_error:  number of bit differences from the best pattern
        rotation:    rotation index that matched best
    """
    patterns = getattr(config, 'PATTERNS', {})
    best_type = 'unknown'
    best_error = grid.size + 1
    best_rotation = 0

    rotated = grid.copy()
    for rotation in range(4):
        for marker_type, pattern in patterns.items():
            error = hamming_distance(rotated, pattern)
            if error < best_error:
                best_type = marker_type
                best_error = error
                best_rotation = rotation
        rotated = rotate_grid_90(rotated)

    if best_error > max_hamming:
        return 'unknown', best_error, best_rotation
    return best_type, best_error, best_rotation


def marker_scale(marker):
    return float(np.sqrt(max(marker.get('area', 0.0), 1.0)))


def is_duplicate(a, b, center_fraction=DEFAULT_DUPLICATE_CENTER_FRACTION):
    ax, ay = a['center']
    bx, by = b['center']
    center_distance = float(np.hypot(ax - bx, ay - by))
    scale = max(marker_scale(a), marker_scale(b))
    return center_distance < center_fraction * scale


def marker_rank(marker):
    # Known marker beats unknown; lower grid error beats higher; larger area is
    # usually the outer border and is more stable than an inner duplicate.
    known_score = 0 if marker['type'] != 'unknown' else 1
    return (known_score, marker.get('match_error', 99), -marker.get('area', 0.0))


def suppress_duplicates(markers):
    kept = []
    for marker in sorted(markers, key=marker_rank):
        if any(is_duplicate(marker, existing) for existing in kept):
            continue
        kept.append(marker)
    return kept


def find_markers(gray=None, frame=None, min_area=1000, max_area=50000, include_unknown=True, **kwargs):
    """
    Detect and classify custom grid markers.

    Each returned marker has the same shape downstream code expects:
        corners, center, area, type

    Extra debug fields:
        grid, match_error, rotation
    """
    if gray is None:
        if frame is None:
            print('ERROR: Need grayscale image or BGR frame')
            return []
        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)

    source = frame if frame is not None else gray
    candidates = find_squares(gray=gray, min_area=min_area, max_area=max_area, **kwargs)
    markers = []

    for candidate in candidates:
        patch = warp_to_patch(source, candidate['corners'])
        grid = extract_grid(patch)
        marker_type, match_error, rotation = classify_grid(grid)
        if marker_type == 'unknown' and not include_unknown:
            continue

        marker = dict(candidate)
        marker.update({
            'type': marker_type,
            'grid': grid,
            'match_error': match_error,
            'rotation': rotation,
        })
        markers.append(marker)

    return suppress_duplicates(markers)

# gate_finder.py - Find valid gates from detected and identified markers

from config import AREA_MATCH_THRESHOLD, ANGLE_MAX_DEGREES
from math_utils import angle_between, midpoint, distance


def gate_metrics(left, right):
    larger = max(left['area'], right['area'])
    smaller = min(left['area'], right['area'])
    area_diff = (larger - smaller) / larger if larger > 0 else 1.0
    angle = angle_between(left['center'], right['center'])
    width = distance(left['center'], right['center'])
    return area_diff, angle, width


def gate_score(area_diff, angle, width):
    area_quality = max(0.0, 1.0 - (area_diff / AREA_MATCH_THRESHOLD))
    angle_quality = max(0.0, 1.0 - (angle / ANGLE_MAX_DEGREES))
    return width * (0.55 + 0.30 * area_quality + 0.15 * angle_quality)


def find_gates(markers):
    """
    Given a list of identified markers, find all valid gate pairs.

    Each marker dict (from square_finder + pattern_reader) must have:
        'corners': numpy array (4, 2)
        'center':  (cx, cy)
        'area':    float
        'type':    'left', 'right', or 'unknown'

    Returns a list of valid gates. Each gate is:
        {
            'left':   left marker dict,
            'right':  right marker dict,
            'center': [cx, cy]  midpoint between the two markers,
            'width':  float     pixel distance between the two centers
        }
    """
    gates = []

    left_markers = [m for m in markers if m['type'] == 'left']
    right_markers = [m for m in markers if m['type'] == 'right']

    for left in left_markers:
        for right in right_markers:
            area_diff, angle, gate_width = gate_metrics(left, right)
            if area_diff > AREA_MATCH_THRESHOLD:
                continue
            if angle > ANGLE_MAX_DEGREES:
                continue

            gate_center = midpoint(left['center'], right['center'])

            gates.append({
                'left': left,
                'right': right,
                'center': gate_center,
                'width': gate_width,
                'area_diff': area_diff,
                'angle': angle,
                'score': gate_score(area_diff, angle, gate_width),
                'stale': False,
            })

    return gates


def best_gate(gates):
    """
    If multiple valid gates are found, pick the most relevant one.
    Strategy: widest gate = closest to camera = highest priority.
    """
    if not gates:
        return None

    return max(gates, key=lambda g: g.get('score', g['width']))

# gate_tracker.py - Smooth gate position and bridge short detection dropouts.

from config import GATE_MEMORY_FRAMES, GATE_SMOOTHING_ALPHA


def lerp(a, b, alpha):
    return (1.0 - alpha) * float(a) + alpha * float(b)


def blend_point(old, new, alpha):
    return [
        lerp(old[0], new[0], alpha),
        lerp(old[1], new[1], alpha),
    ]


class GateTracker:
    def __init__(self, memory_frames=GATE_MEMORY_FRAMES, alpha=GATE_SMOOTHING_ALPHA):
        self.memory_frames = memory_frames
        self.alpha = alpha
        self.last_gate = None
        self.missed_frames = 0

    def reset(self):
        self.last_gate = None
        self.missed_frames = 0

    def update(self, gate):
        if gate is not None:
            self.missed_frames = 0
            if self.last_gate is None:
                self.last_gate = dict(gate)
            else:
                smoothed = dict(gate)
                smoothed['center'] = blend_point(self.last_gate['center'], gate['center'], self.alpha)
                smoothed['width'] = lerp(self.last_gate['width'], gate['width'], self.alpha)
                smoothed['stale'] = False
                self.last_gate = smoothed
            return self.last_gate

        if self.last_gate is None:
            return None

        self.missed_frames += 1
        if self.missed_frames > self.memory_frames:
            self.reset()
            return None

        held = dict(self.last_gate)
        held['stale'] = True
        held['missed_frames'] = self.missed_frames
        return held

import math
import numpy as np

def shoelace_area(corners):
    """
    Calculate area of polygon using Shoelace Formula (Gauss's Area Formula)
    Input: corners = [[x1,y1], [x2,y2], [x3,y3], [x4,y4]] (list of 4 points)
    Output: area in pixels (float)
    
    Formula: Area = 0.5 * |sum of (x[i]*y[i+1] - x[i+1]*y[i])|
    Like tying shoelaces with coordinates!
    """
    corners = np.array(corners)
    n = len(corners)
    
    # Shoelace calculation
    area = 0.0
    for i in range(n):
        j = (i + 1) % n  # Wrap around to first point
        area += corners[i][0] * corners[j][1]  # x[i] * y[j]
        area -= corners[j][0] * corners[i][1]  # x[j] * y[i]
    
    area = abs(area) / 2.0
    return area


def distance(point1, point2):
    """
    Euclidean distance between two points
    
    Input: point1 = [x1, y1], point2 = [x2, y2]
    Output: distance in pixels (float)
    
    Formula: sqrt((x2-x1)^2 + (y2-y1)^2) - Pythagorean theorem
    """
    x1, y1 = point1
    x2, y2 = point2
    dist = math.sqrt((x2 - x1)**2 + (y2 - y1)**2)
    return dist


def angle_between(point1, point2):
    """
    Calculate angle between two points relative to horizontal X-axis
    
    Input: point1 = [x1, y1] (left marker), point2 = [x2, y2] (right marker)
    Output: angle in degrees (0-90)
    
    Formula: arctan(|y2-y1| / |x2-x1|) converted to degrees
    """
    x1, y1 = point1
    x2, y2 = point2
    
    dx = abs(x2 - x1)
    dy = abs(y2 - y1)
    
    # Avoid division by zero
    if dx == 0:
        return 90.0  # Vertical line
    
    angle_rad = math.atan(dy / dx)
    angle_deg = math.degrees(angle_rad)
    return angle_deg


def midpoint(point1, point2):
    """
    Calculate midpoint (average) of two points
    Used to find gate center between left and right markers
    
    Input: point1 = [x1, y1], point2 = [x2, y2]
    Output: [x_mid, y_mid] (center point)
    
    Formula: [(x1+x2)/2, (y1+y2)/2]
    """
    x1, y1 = point1
    x2, y2 = point2
    mid_x = (x1 + x2) / 2.0
    mid_y = (y1 + y2) / 2.0
    return [mid_x, mid_y]


def point_in_bounds(point, img_width, img_height):
    """
    Check if point is inside image boundaries
    Prevents processing markers outside frame
    
    Input: point = [x, y], img_width, img_height (from config)
    Output: True if inside, False if outside
    """
    x, y = point
    if 0 <= x < img_width and 0 <= y < img_height:
        return True
    return False

def x_to_letter(gate_center_x, uppercase=True):
    """
    Map gate center X position (0 to IMG_WIDTH) to a letter A-Z or a-z.

    Frame divided into 26 equal zones (~24.6px each):
      A = far left, M/N = center, Z = far right.

    Args:
        gate_center_x: pixel X coordinate of gate midpoint
        uppercase: True for odd gates (1,3,5...), False for even gates (2,4,6...)

    Returns:
        Single character, e.g. 'A', 'N', 'z'
    """
    clamped_x = max(0.0, min(float(gate_center_x), float(IMG_WIDTH)))
    zone_width = IMG_WIDTH / LETTER_NUM_ZONES
    zone_index = int(clamped_x / zone_width)
    if zone_index >= LETTER_NUM_ZONES:
        zone_index = LETTER_NUM_ZONES - 1

    if uppercase:
        return chr(ord('A') + zone_index)
    else:
        return chr(ord('a') + zone_index)

    """
    Map gate centre x position to a steering command.

    Args:
        gate_center_x: x pixel coordinate of the gate midpoint

        command: one of 'strong_left', 'light_left', 'go',
                         'light_right', 'strong_right'
        led_pin: GPIO pin number to activate (from config)
    """
    if gate_center_x < ZONE_STRONG_LEFT:
        command = 'strong_left'
    elif gate_center_x < ZONE_LIGHT_LEFT:

    elif gate_center_x <= ZONE_LIGHT_RIGHT:

    elif gate_center_x <= ZONE_STRONG_RIGHT:

# pattern_reader.py - Read and identify marker patterns
# Takes a detected square, unwarps it via perspective transform,
# reads the inner NxN binary grid, and matches against known patterns.

import numpy as np
import cv2
from config import PATTERNS

# Grid size is read dynamically from config (currently 4x4)
GRID_SIZE = len(list(PATTERNS.values())[0])

# Size of the normalised patch we warp each marker into
# 80px: border=16px each side, inner=48px, cell=12px per side
PATCH_SIZE = 80

# Black border takes up 20% on each side → inner region is 60% of patch
BORDER_FRACTION = 0.2


def warp_to_patch(frame, corners):
    """
    Perspective-warp the detected square into a flat PATCH_SIZE x PATCH_SIZE image.

    corners: numpy array (4, 2), ordered [TL, TR, BR, BL]
    Returns: warped patch (grayscale)
    """
    dst = np.array([
        [0,             0],
        [PATCH_SIZE - 1, 0],
        [PATCH_SIZE - 1, PATCH_SIZE - 1],
        [0,             PATCH_SIZE - 1]
    ], dtype=np.float32)

    src = corners.astype(np.float32)
    H = cv2.getPerspectiveTransform(src, dst)
    patch = cv2.warpPerspective(frame, H, (PATCH_SIZE, PATCH_SIZE))

    # Convert to grayscale for thresholding
    if len(patch.shape) == 3:
        patch = cv2.cvtColor(patch, cv2.COLOR_BGR2GRAY)

    return patch


def extract_grid(patch):
    """
    Convert the warped patch into an NxN binary grid (N = GRID_SIZE).

    Returns: numpy array (N, N) where 1 = black cell, 0 = white cell
    """
    # Otsu threshold → clean black/white image
    _, binary = cv2.threshold(patch, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)

    # Crop out the black border to get the inner pattern region
    border = int(PATCH_SIZE * BORDER_FRACTION)
    inner = binary[border:PATCH_SIZE - border, border:PATCH_SIZE - border]

    cell_size = inner.shape[0] // GRID_SIZE
    grid = np.zeros((GRID_SIZE, GRID_SIZE), dtype=int)

    for row in range(GRID_SIZE):
        for col in range(GRID_SIZE):
            cell = inner[row * cell_size:(row + 1) * cell_size,
                         col * cell_size:(col + 1) * cell_size]
            # Black pixels = 0 in binary image → mean < 127 means mostly black
            grid[row][col] = 1 if np.mean(cell) < 127 else 0

    return grid


def rotate_grid_90(grid):
    """Rotate grid 90 degrees clockwise."""
    return np.rot90(grid, k=-1)


def read_pattern(frame, corners):
    """
    Main function: identify which marker type a detected square is.

    Args:
        frame:   full camera frame (BGR or grayscale)
        corners: numpy array (4, 2), corners ordered [TL, TR, BR, BL]

    Returns:
        marker_type: 'left', 'right', or 'unknown'
        grid:        the NxN binary grid that was read (for debugging)
    """
    # 1. Unwarp the square into a flat patch
    patch = warp_to_patch(frame, corners)

    # 2. Read the NxN binary grid from the inner region
    grid = extract_grid(patch)

    # 3. Try all 4 rotations against every known pattern
    rotated = grid.copy()
    for _ in range(4):
        for name, pattern in PATTERNS.items():
            if np.array_equal(rotated, np.array(pattern)):
                return name, grid
        rotated = rotate_grid_90(rotated)

    return 'unknown', grid

def order_corners(corners):
    """
    Order 4 corners consistently: top-left, top-right, bottom-right, bottom-left
    """
    pts = np.array(corners, dtype=np.float32)
    rect = np.zeros((4, 2), dtype=np.float32)
    
    s = pts.sum(axis=1)
    rect[0] = pts[np.argmin(s)]      # top-left
    rect[2] = pts[np.argmax(s)]      # bottom-right
    
    diff = np.diff(pts, axis=1)
    rect[1] = pts[np.argmin(diff)]   # top-right
    rect[3] = pts[np.argmax(diff)]   # bottom-left
    
    return rect

    """
    Direct contour detection using adaptive threshold (quads.py approach)
    Simple and robust - no Hough lines needed
    """
    try:
        # Adaptive threshold finds local contrast changes = marker borders
        blur = cv2.GaussianBlur(gray, (5, 5), 0)
        thresh = cv2.adaptiveThreshold(
            blur, 255,
            cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
            cv2.THRESH_BINARY_INV,
            11, 2
        )

        # Light morphology to clean up noise
        kernel = np.ones((3, 3), np.uint8)
        thresh = cv2.morphologyEx(thresh, cv2.MORPH_CLOSE, kernel, iterations=1)

        # Find contours
        contours, _ = cv2.findContours(thresh, cv2.RETR_TREE, cv2.CHAIN_APPROX_SIMPLE)

    except cv2.error as e:
        print(f"OpenCV error in preprocessing: {e}")
        return []
    except Exception as e:
        print(f"Unexpected error in preprocessing: {e}")
        return []

    markers = []
    
    for contour in contours:
        try:
            area = cv2.contourArea(contour)

            
            if area < min_area or area > max_area:
                continue

            perimeter = cv2.arcLength(contour, True)
            approx = cv2.approxPolyDP(contour, 0.04 * perimeter, True)

            # Must be a quadrilateral
            if len(approx) != 4:
                continue

            # Must be convex
            if not cv2.isContourConvex(approx):
                continue

            corners = approx.reshape(-1, 2).astype(np.float32)
            ordered = order_corners(corners)

            # Check aspect ratio using minimum area rectangle
            rect = cv2.minAreaRect(corners)
            w, h = rect[1]
            if w < 20 or h < 20:
                continue

            ratio = max(w, h) / min(w, h)

            # ArUco markers are SQUARE - ratio should be close to 1.0
            if ratio > 1.5:
                continue

            # Check side lengths for squareness
            side_lengths = []
            for i in range(4):
                p1 = ordered[i]
                p2 = ordered[(i + 1) % 4]
                length = distance(p1.tolist(), p2.tolist())
                side_lengths.append(length)

            side_ratio = max(side_lengths) / (min(side_lengths) + 1e-6)
            if side_ratio > 1.6:
                continue

            precise_area = shoelace_area(ordered.tolist())
            cx = np.mean(ordered[:, 0])
            cy = np.mean(ordered[:, 1])

            markers.append({
                'corners': ordered,
                'center': (cx, cy),
                'area': precise_area
            })
        except Exception as e:
            # Skip problematic contours
            continue
    
    return markers

class ReusableHTTPServer(HTTPServer):
    allow_reuse_address = True


def create_stream_server(handler_class, preferred_port, host="0.0.0.0", max_tries=10):
    """Bind the stream server, falling back if the preferred port is busy."""
    last_error = None

    for port in range(preferred_port, preferred_port + max_tries):
        try:
            server = ReusableHTTPServer((host, port), handler_class)
            if port != preferred_port:
                print(f"[stream] Port {preferred_port} is busy; using {port} instead.")
            return server, port
        except OSError as exc:
            last_error = exc
            if exc.errno != errno.EADDRINUSE:
                raise

    raise RuntimeError(
        f"Could not bind stream server on ports {preferred_port}-"
        f"{preferred_port + max_tries - 1}. Stop the old process or choose "
        "a different stream port."
    ) from last_error


def stream_url(port):
    hostname = socket.gethostname().split(".")[0]
    return f"http://{hostname}.local:{port}"
