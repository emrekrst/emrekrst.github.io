# Serial-controlled PWM DAC with PID feedback

An ATmega644P coursework example combining 8-bit PWM, ADC feedback, a serial command interface and a Python/Tkinter control panel with a 50-sample freehand waveform editor. The source implements bounded integral accumulation and PWM saturation. An external RC low-pass filter converts PWM into an approximate analogue voltage.

## What was recovered

- `embedded_skeleton.c`: AVR application, including manual/PID operation and ADC monitoring.
- `debug.h`: supplied UART stream library credited to Steve Gunn; its existing Creative Commons Attribution notice is retained.
- `gui_plus.py`: recovered GUI including waveform drawing. `gui.py` now launches this consolidated GUI.

**`pwm_cli.cpp` is a newly reconstructed POSIX C++ client. The historical C++ host CLI mentioned in the master CV was not recovered.** `protocol.c/.h`, tests and build/docs were added during preparation. The recovered firmware's unsafe command parsing and truncated-line handling were fixed; ADC targets and PWM are bounded, and firmware gain commands now match the recovered GUI controls. These are changes to the standalone copy only.

## Build and test without hardware

Requires GCC/Clang, Make, Python 3 with Tk, and pySerial. AVR compilation requires avr-gcc and avr-libc.

```sh
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install -r requirements.txt
make
make test
make firmware                 # AVR_CC=/path/to/avr-gcc if needed
```

`make test` opens local pseudoterminals, not physical serial devices. It checks command framing, parser bounds/ranges, GUI logic and C++/pySerial transport. `make firmware` only builds an ELF; it does not flash a board. Outputs remain in ignored `build/`.

## Host use with a separately verified circuit

```sh
python3 gui_plus.py
./build/pwm_cli /dev/ttyUSB0 READ
./build/pwm_cli /dev/ttyUSB0 SET 128
./build/pwm_cli /dev/ttyUSB0 AUTO 512
./build/pwm_cli /dev/ttyUSB0 MONITOR    # Ctrl-C sends STOP and exits
```

Select the actual port in the GUI. The client examples are usage instructions; no physical port or board was accessed during preparation. The new CLI supports macOS/Linux POSIX serial devices at 9600 baud, 8 data bits, no parity, one stop bit. It does not provide a Windows backend.

## Firmware connections and assumptions

The source configures a **12 MHz** CPU clock, UART0 at **9600 8N1**, timer0 fast PWM on **PORTB bit 3 / OC0A**, and ADC **channel 0** feedback. The RC-filter output feeds ADC0 and the measurement instrument; all signal grounds must share a reference. Connect UART0 through a logic-level-compatible USB–UART adapter. Package pin numbers depend on the actual MCU package and must be checked against its datasheet.

The ADC selects **AVCC** as reference (`REFS0`). The GUI's voltage conversion assumes that reference is **3.3 V**, as stated in the CV. Confirm actual AVCC, PWM high voltage and ADC input limits before using that conversion. No recovered schematic, RC component values or load value is included; choose and measure a circuit appropriate to the board rather than treating the display labels as calibration.

## Command schema

Commands are ASCII, case-sensitive and terminated by CR or LF. Oversized lines (more than 49 characters) are discarded entirely. Missing numeric arguments, nonnumeric/trailing data, unknown tokens and unsupported extra arguments produce `ERR invalid command`.

| Command | Effect / units |
| --- | --- |
| `SET n` | Disable PID and monitoring; PWM saturated to 0–255 |
| `AUTO n` | Enable PID, reset history; ADC target saturated to 0–1023 |
| `READ` | One `ADC: n | PWM: n` response |
| `MONITOR` | Start repeated ADC/PWM text readings |
| `STOP` | Stop monitoring; **does not disable PID or force PWM to zero** |
| `KP n`, `KI n`, `KD n` | Gain in thousandths, integer range 0–30000 |

Any incoming byte also stops monitoring, matching the original firmware. `SET 0` explicitly disables PID and commands zero duty cycle. PWM waveform playback sends 50 duty-cycle samples using cancellable Tk callbacks scheduled 50 ms apart; it is not a precision waveform generator. Serial delays and OS scheduling affect timing. Mode changes cancel queued waveform callbacks; playback and UI commands execute on the same Tk thread.

The original discrete PID is empirically tuned in iterations; it has no measured fixed-period scheduler or explicit time scaling. The nominal 100 µs loop delay excludes ADC/serial execution time. Monitor timing and waveform amplitude/frequency require bench measurement.

This project corresponds to the master CV's serial PWM DAC project. Historical oscilloscope, load-transient and physical voltage-regulation statements come from that CV and were **not reverified** here. No new physical measurement is claimed. See [VERIFICATION.md](VERIFICATION.md).

# Verification

Executed on 2026-10-22 on macOS arm64: Apple clang 17.0.0, Python 3.14.0, pySerial 3.5, Homebrew avr-gcc 9.5.0. No board, physical serial port, camera or motor was opened or operated.

```sh
make test
make firmware AVR_CC=/opt/homebrew/bin/avr-gcc
```

Both commands PASS, exit 0, no compiler warnings. Firmware uses `-mmcu=atmega644p -DF_CPU=12000000UL -Os` and links the shared parser with the application and supplied UART header.

- Shared C parser/framing tests execute with AddressSanitizer and UndefinedBehaviorSanitizer: missing/long/unknown tokens, malformed and overflowing integers, extra parameters, SET/AUTO saturation, gains, READ/MONITOR/STOP, oversized-line rejection and recovery.
- GUI method tests check command formatting, acknowledgement-before-ADC handling, ADC-to-voltage display, and bounds of the actual 50-sample drawing array. Additional playback regressions verify cancellation on STOP/AUTO/manual/monitor/disconnect, a single loop after repeated starts, and all 50 samples wrapping in order.
- Reconstructed C++ CLI exchanges SET/AUTO/READ/KP/STOP commands through local pseudoterminals, receives expected text responses and rejects a missing argument before opening a device.
- Recovered GUI's actual `read_once`/`send_cmd` methods exchange a READ/ADC transaction using real pySerial over a pseudoterminal; widget stand-ins allow headless testing.
- Python files compile via `py_compile`.

Before the parser fix, an extracted copy of the original `process_command` produced an AddressSanitizer **stack-buffer-overflow** for a 47-character token. The original GUI regression failed because it sent `READ 0`; after that fix it also needed to skip older acknowledgement lines to display the requested ADC reading. The CLI transport tests were introduced before the new reconstructed client existed.

Fresh review also reproduced a waveform-worker race: a worker paused after its loop condition could send a stale `SET 128` after `AUTO 512`, disabling PID in the firmware. The playback regression failed against the thread-based implementation. Playback now schedules a single cancellable Tk callback, so mode changes and waveform writes run serially on the UI thread. Stop/mode changes/disconnect cancel the pending callback; repeated starts cannot create duplicate loops. The 50-sample sequence and nominal 50 ms scheduling interval are retained.

The transport peer returns canned protocol responses. It is not an AVR emulator or an electrical/circuit model. AVR compilation verifies syntax/linkage for the target, not real-time or physical behaviour.

## NOT_RUN — hardware and runtime limits

- Flashing, actual UART electrical compatibility/baud timing, board clock and pin wiring.
- PWM voltage/ripple and RC filter characteristics; AVCC/reference calibration and physical ADC accuracy.
- PID stability, step response, integral behaviour under a real load, oscilloscope/load-transient CV measurements.
- Monitor cadence, waveform timing/amplitude/frequency and full GUI interaction with hardware.
- Cross-platform GUI thread/connection stress, Windows support and serial disconnect fault injection.

GUI one-shot reads can block up to the serial timeout, and background monitoring relies on a host thread and waveform callbacks use the Tk event loop rather than deterministic scheduling. These limits must be evaluated on the intended board before bench use. All hardware claims remain historical claims, not results generated during this preparation.

/*  Author: Steve Gunn
 * Licence: This work is licensed under the Creative Commons Attribution License.
 *          View this license at http://creativecommons.org/about/licenses/
 *   Notes: F_CPU must be defined to match the clock frequency
 *   Usage: Include in your main file and call init_debug_uart0() from the beginning of main
 *          to initialise redirection of stdout, stderr and stdin to UART0.
 */

#define __ASSERT_USE_STDERR
#include <assert.h>
#include <stdio.h>
#include <avr/io.h>

#define DEBUG_BAUD  9600

int uputchar0(char c, FILE *stream)
{
	if (c == '\n') uputchar0('\r', stream);
	while (!(UCSR0A & _BV(UDRE0)));
	UDR0 = c;
	return c;
}

int ugetchar0(FILE *stream)
{
	(void)stream;
	while(!(UCSR0A & _BV(RXC0)));
	return UDR0;
}

void init_debug_uart0(void)
{
	/* Configure UART0 baud rate, one start bit, 8-bit, no parity and one stop bit */
	UBRR0H = (F_CPU/(DEBUG_BAUD*16L)-1) >> 8;
	UBRR0L = (F_CPU/(DEBUG_BAUD*16L)-1);
	UCSR0B = _BV(RXEN0) | _BV(TXEN0);
	UCSR0C = _BV(UCSZ00) | _BV(UCSZ01);

	/* Setup new streams for input and output */
	static FILE uout = FDEV_SETUP_STREAM(uputchar0, NULL, _FDEV_SETUP_WRITE);
	static FILE uin = FDEV_SETUP_STREAM(NULL, ugetchar0, _FDEV_SETUP_READ);

	/* Redirect all standard streams to UART0 */
	stdout = &uout;
	stderr = &uout;
	stdin = &uin;
}

#ifndef F_CPU
#define F_CPU 12000000UL
#endif

#include <stdlib.h>
#include <string.h>
#include <stdio.h>
#include <avr/io.h>
#include <util/delay.h>
#include "debug.h" 

#include "protocol.h"

float Kp = 0.5;
float Ki = 0.05;
float Kd = 0.001;

int pid_active = 0; 
int monitor_active = 0; 
int target_adc = 0;       
float integral_sum = 0;   
float prev_error = 0;     
long loop_counter = 0; 

void init_adc() {
    ADCSRA |= (1 << ADEN); 
    ADMUX |= (1 << REFS0); 
    ADCSRA |= (1 << ADPS2) | (1 << ADPS1) | (1 << ADPS0); 
}

uint16_t read_adc(uint8_t channel) {
    ADMUX = (ADMUX & 0xF0) | (channel & 0x0F);
    ADCSRA |= (1 << ADSC);
    while (ADCSRA & (1 << ADSC));
    return ADC; 
}

void init_pwm() {
    DDRB |= (1 << PB3); 
    TCCR0A |= (1 << WGM00) | (1 << WGM01) | (1 << COM0A1);
    TCCR0B |= (1 << CS00);
}

void set_pwm(uint8_t value) {
    OCR0A = value; 
}

void update_pid() {
    if (!pid_active) return;

    int current_val = read_adc(0);
    float error = target_adc - current_val;
    float derivative = error - prev_error;
    integral_sum += error;

    if (integral_sum > 5000) integral_sum = 5000;
    if (integral_sum < -5000) integral_sum = -5000;

    float output = (Kp * error) + (Ki * integral_sum) + (Kd * derivative);

    prev_error = error;
    
    if (output > 255) output = 255;
    if (output < 0) output = 0;

    set_pwm((uint8_t)output);
}

void process_command(char* input_buffer) {
    command cmd;
    if (!parse_command(input_buffer, &cmd)) {
        printf("ERR invalid command\n"); return;
    }
    switch (cmd.kind) {
        case CMD_SET:
            pid_active = 0; monitor_active = 0;
            set_pwm((uint8_t)cmd.value);
            printf("Manual PWM: %d\n", cmd.value); break;
        case CMD_AUTO:
            pid_active = 1; target_adc = cmd.value;
            integral_sum = 0; prev_error = 0;
            printf("PID ON. Target: %d\n", target_adc); break;
        case CMD_MONITOR:
            monitor_active = 1; loop_counter = 0;
            printf("Monitoring ADC... Press ENTER key to stop.\n"); break;
        case CMD_READ:
            printf("ADC: %u | PWM: %u\n", read_adc(0), (unsigned)OCR0A); break;
        case CMD_STOP:
            monitor_active = 0;
            printf("Monitor stopped\n"); break;
        case CMD_KP: Kp = cmd.value / 1000.0f; printf("KP updated\n"); break;
        case CMD_KI: Ki = cmd.value / 1000.0f; printf("KI updated\n"); break;
        case CMD_KD: Kd = cmd.value / 1000.0f; printf("KD updated\n"); break;
    }
}

int main(void) {
    command_buffer buffer = {{0}, 0, 0};
    
    init_debug_uart0(); 
    init_adc();         
    init_pwm();         
    
    printf("SYSTEM READY\n");

    while(1) {
        if (UCSR0A & (1 << RXC0)) { //STATE REG
            char c = UDR0; 
            
            if (monitor_active) {
                monitor_active = 0;
                printf("\n[Monitor Stopped]\n");
            }
            
            int result = command_feed(&buffer, c);
            if (result == 1) process_command(buffer.text);
            else if (result == -1) printf("ERR command too long\n");
        }

        update_pid();

        if (monitor_active) {
            loop_counter++;
            // 0.1ms * 500 = 50ms
            if (loop_counter >= 500) { 
                int val = read_adc(0);
                printf("ADC: %d | PWM: %d\n", val, OCR0A);
                loop_counter = 0;
            }
        }

        _delay_us(100); 
    }
}

    def refresh_ports(self):
        ports = [p.device for p in serial.tools.list_ports.comports()]
        self.port_combo['values'] = ports
        if ports: self.port_combo.current(0)

    def toggle_connection(self):
        if self.ser and self.ser.is_open:
            self.stop_monitor()
            self.stop_wave()
            self.ser.close()
            self.status_canvas.itemconfig(self.status_circle, fill="red")
            self.btn_connect.config(text="Connect")
        else:
            try:
                self.ser = serial.Serial(self.port_combo.get(), 9600, timeout=1)
                self.status_canvas.itemconfig(self.status_circle, fill="green")
                self.btn_connect.config(text="Disconnect")
            except Exception as e:
                print("Connection error:", e)


    def send_cmd(self, cmd):
        if self.ser and self.ser.is_open:
            full_cmd = cmd + "\r" 
            self.ser.write(full_cmd.encode())

    def send_auto(self):
        self.stop_wave()
        self.send_cmd(f"AUTO {self.slider_target.get()}")

    def send_pwm(self):
        self.stop_wave()
        self.send_cmd(f"SET {self.slider_pwm.get()}")

    def send_pid(self):
        try:
            kp = int(float(self.entry_kp.get()) * 1000)
            ki = int(float(self.entry_ki.get()) * 1000)
            kd = int(float(self.entry_kd.get()) * 1000)
            self.send_cmd(f"KP {kp}")
            time.sleep(0.05)
            self.send_cmd(f"KI {ki}")
            time.sleep(0.05)
            self.send_cmd(f"KD {kd}")
        except:
            print("Invalid PID")

    def read_once(self):
        if not self.ser: return
        curr = self.lbl_current.cget("text")
        if "Current:" in curr:
            self.lbl_prev.config(text=curr.replace("Current:", "Previous:"))
        self.send_cmd("READ")
        try:
            # Earlier command acknowledgements can precede the requested ADC line.
            for _ in range(10):
                line = self.ser.readline().decode().strip()
                if not line:
                    break
                if line.startswith("ADC:"):
                    self.update_display(line)
                    break
        except: pass

    def update_display(self, line):
        try:
            parts = line.split('|')
            adc_val = int(parts[0].split(':')[1])
            voltage = (adc_val / 1023.0) * 3.3
            pwm_str = parts[1].split(':')[1].strip() if len(parts) > 1 else "--"
            self.lbl_current.config(text=f"Current: {voltage:.2f} V (ADC: {adc_val}) | PWM: {pwm_str}")
        except: pass

    def draw_grid(self):
        self.cv.delete("all")
        self.cv.create_line(0, self.cv_height-1, self.cv_width, self.cv_height-1, fill="gray")
        self.cv.create_line(0, 0, self.cv_width, 0, fill="gray")
        self.cv.create_text(10, 10, text="3.3V (255)", anchor="w")
        self.cv.create_text(10, self.cv_height-10, text="0V (0)", anchor="w")

    def clear_wave(self):
        self.draw_grid()
        self.wave_data = [0] *self.wave_resolution


    def draw_wave(self, event):
        x = event.x
        if x < 0: x = 0
        if x >= self.cv_width: x = self.cv_width - 1
        
        index = int((x / self.cv_width) * self.wave_resolution)
        
        y = event.y
        if y < 0: y = 0
        if y > self.cv_height: y = self.cv_height
        
        pwm_val = int(255 - (y / self.cv_height * 255))
        
        self.wave_data[index] = pwm_val
        
        r = 2
        self.cv.create_oval(x-r, y-r, x+r, y+r, fill="blue", outline="blue")

    def start_wave(self):
        if not self.ser or not self.ser.is_open: return
        self.stop_wave()
        self.stop_monitor()
        self.wave_playing = True
        self.wave_index = 0
        self.btn_play_wave.config(state="disabled")
        self.btn_stop_wave.config(state="normal")
        self.wave_after_id = self.root.after(0, self.wave_loop)

    def stop_wave(self):
        self.wave_playing = False
        if self.wave_after_id is not None:
            self.root.after_cancel(self.wave_after_id)
            self.wave_after_id = None
        self.btn_play_wave.config(state="normal")
        self.btn_stop_wave.config(state="disabled")

    def wave_loop(self):
        # Tk runs this callback and mode changes serially: no stale SET after AUTO.
        self.wave_after_id = None
        if not self.wave_playing or not self.ser or not self.ser.is_open:
            self.stop_wave()
            return
        try:
            self.send_cmd(f"SET {self.wave_data[self.wave_index]}")
            if self.ser.in_waiting:
                self.ser.read_all()
        except Exception:

int parse_command(const char* text, command* out) {
    const char* names[]={"SET","AUTO","READ","MONITOR","STOP","KP","KI","KD"};
    while (isspace((unsigned char)*text)) ++text;
    const char* end=text;
    while (*end && !isspace((unsigned char)*end)) ++end;
    unsigned n=(unsigned)(end-text), kind;
    for(kind=0;kind<sizeof names/sizeof names[0];++kind)
        if(strlen(names[kind])==n && strncmp(text,names[kind],n)==0) break;
    if(kind==sizeof names/sizeof names[0]) return 0;
    while(isspace((unsigned char)*end)) ++end;
    long value=0;
    if(kind==CMD_SET || kind==CMD_AUTO || kind>=CMD_KP) {
        if(!*end) return 0;
        char* tail;
        errno=0; value=strtol(end,&tail,10);
        if(tail==end || errno==ERANGE) return 0;
        while(isspace((unsigned char)*tail)) ++tail;
        if(*tail) return 0;
        if(kind>=CMD_KP && (value<0 || value>30000)) return 0;
        if(kind==CMD_SET || kind==CMD_AUTO) {
            long max=kind==CMD_SET ? 255 : 1023;
            if(value<0) value=0;
            if(value>max) value=max;
        }
    } else if(*end) return 0;
    out->kind=(command_kind)kind; out->value=(int)value;
    return 1;
}
int command_feed(command_buffer* b,char byte) {
    if(byte=='\r' || byte=='\n') {
        int result=b->overflow ? -1 : (b->length ? 1 : 0);
        b->text[b->length]='\0'; b->length=0; b->overflow=0;
        return result;
    }
    if(b->length+1<sizeof b->text && !b->overflow) b->text[b->length++]=byte;
    else b->overflow=1;
    return 0;
}

#include "protocol.h"

#include <cstdio>
#include <cstring>
#include <iostream>
#include <string>

#include <termios.h>
#include <unistd.h>
static volatile std::sig_atomic_t running = 1;
static void stop(int) { running = 0; }
static bool send_all(int fd, const std::string& message) {
    size_t sent = 0;
    while (sent < message.size()) {
        ssize_t n = write(fd, message.data() + sent, message.size() - sent);
        if (n < 0 && errno == EINTR) continue;
        if (n <= 0) return false;
        sent += static_cast<size_t>(n);
    }
    return true;
}
int main(int argc, char** argv) {
    if (argc < 3 || argc > 4) {
        std::cerr << "Usage: pwm_cli PORT 'READ|MONITOR|STOP' or PORT 'SET|AUTO|KP|KI|KD' INTEGER\n";
        return 2;
    }
    std::string text = argv[2];
    if (argc == 4) text += " " + std::string(argv[3]);
    command cmd;
    if (!parse_command(text.c_str(), &cmd)) {
        std::cerr << "Invalid command or argument\n"; return 2;
    }
    int fd = open(argv[1], O_RDWR | O_NOCTTY);
    if (fd < 0) { std::perror("open serial port"); return 1; }
    termios original{}, settings{};
    if (tcgetattr(fd, &original) < 0) { std::perror("tcgetattr"); close(fd); return 1; }
    settings = original;
    cfmakeraw(&settings);
    cfsetispeed(&settings, B9600); cfsetospeed(&settings, B9600);
    settings.c_cflag |= CLOCAL | CREAD;
    settings.c_cflag &= ~CSTOPB;
    settings.c_cc[VMIN] = 0; settings.c_cc[VTIME] = 0;
    if (tcsetattr(fd, TCSANOW, &settings) < 0) { std::perror("tcsetattr"); close(fd); return 1; }
    std::signal(SIGINT, stop); std::signal(SIGTERM, stop);
    bool okay = send_all(fd, text + "\r"), received = false;
    while (okay && running) {
        pollfd port{fd, POLLIN, 0};
        int ready = poll(&port, 1, cmd.kind == CMD_MONITOR ? 500 : (received ? 200 : 2000));
        if (ready < 0 && errno == EINTR) continue;
        if (ready < 0) { std::perror("poll"); okay = false; break; }
        if (!ready) {
            if (cmd.kind == CMD_MONITOR) continue;
            if (!received) { std::cerr << "No response from board\n"; okay = false; }
            break;
        }
        if (port.revents & (POLLERR | POLLNVAL | POLLHUP)) { okay = false; break; }
        char buffer[256];
        ssize_t n = read(fd, buffer, sizeof buffer);
        if (n < 0 && errno == EINTR) continue;
        if (n <= 0) { okay = false; break; }
        std::cout.write(buffer, n); std::cout.flush(); received = true;
    }
    if (cmd.kind == CMD_MONITOR) send_all(fd, "STOP\r");
    tcsetattr(fd, TCSANOW, &original); close(fd);
    return okay ? 0 : 1;
}

class Scheduler:
    def __init__(self): self.jobs={}; self.next_id=0
    def after(self,delay,callback,*args):
        self.next_id+=1
        self.jobs[self.next_id]=(delay,callback,args)
        return self.next_id
    def after_cancel(self,job): del self.jobs[job]
    def run_next(self):
        job=next(iter(self.jobs))
