# Turbojet speed-control simulation

An educational MATLAB/Simulink model by Emre Karausta, developed independently during an internship learning exercise. Two illustrative plants share a throttle/altitude speed schedule, steady-state fuel feedforward, a PI correction, acceleration/deceleration fuel schedules, a fuel rate limiter and transport delay. One plant uses a first-order speed response; the other uses a nonlinear normalized-spool equation.

The lookup tables and spool coefficients are illustrative generated inputs. They are not validated engine maps. Fuel units were ambiguous in the original comments, so numerical fuel values are reported in model units. RPM is a percentage of nominal speed.

## Run

Requires MATLAB R2024b and Simulink.

```sh
python3 verify.py
```

`MATLAB_BIN` can select MATLAB. Close already-open target models before running; preflight refuses them without changing or closing them. Unrelated models are left intact. The wrapper isolates preferences, working directory and temporary files, enforces a 600-second process timeout, and writes generated traces/cache to ignored `results/`. `run_all.m` initializes every required variable through `Simulink.SimulationInput`; no manual `datas` run or base-workspace setup is needed.

For each plant, the runner tests the saved throttle step, constant zero throttle, and a full-throttle-to-idle command. It checks finite nonnegative RPM, fuel target bounds, PI clamping configuration and final tracking within one RPM percentage point. Logging and scenario overrides exist only in memory. No original model tuning was changed.

Anti-windup is the PI block's own output clamping. External acceleration, deceleration and rate limits do not feed an explicit tracking anti-windup loop. The tests demonstrate simulated behavior under the documented scenarios, not engine-operating limits or production FADEC performance.

See [VERIFICATION.md](VERIFICATION.md), compact `evidence/` and [ATTRIBUTION.md](ATTRIBUTION.md). No hardware was connected or actuated, and nothing was published.

# Verification — 22 October 2026

`python3 verify.py` completed with exit 0 using MATLAB 24.2.0.2923080 (R2024b) Update 6 and Simulink 24.2 on macOS 15.7.3, Apple Silicon. MATLAB ran in a temporary cwd with isolated preferences/TMPDIR and a 600-second process timeout. Only copies were opened. See `evidence/results.json` and `evidence/verification.log`.

The final wrapper also passes a regression confirming already-loaded targets are refused intact and unrelated unsaved models remain open. All six 90-second scenarios passed: the saved throttle step, constant zero throttle, and full throttle until 45 s followed by zero throttle, for each saved plant. Tests assert finite nonnegative RPM, the 180-unit deceleration fuel floor, acceleration-fuel schedule bounds, PI internal clamping configuration, and final absolute tracking error below one RPM percentage point. The existing rate-limiter blocks remain ±3000 model fuel units/s; a separate numerical slew-rate assertion was not added.

|---|---:|---:|---:|
| First-order, saved 25→30% throttle step | 75.0485098674 | 75 | 0.0485098674 |
| First-order, zero throttle | 40 | 40 | 0 |
| First-order, 100→0% throttle | 40.0000210089 | 40 | 0.0000210089 |
| Nonlinear, saved 50→55% throttle step | 87.5000000000 | 87.5 | 1.9e−11 |
| Nonlinear, zero throttle | 40 | 40 | 0 |
| Nonlinear, 100→0% throttle | 40.0000000066 | 40 | 6.6e−9 |

Maximum fuel-schedule excess was 4.55e−13 (round-off). The full-to-idle target fuel ranged from 180 to 1770.1577 for the first-order plant and 180 to 2629.2714 for the nonlinear plant. Tables and full numerical output are recorded in JSON.

The master CV's simulated throttle regulation and idle-at-zero-throttle claims are supported by these runs. The models contain PI controllers with `AntiWindupMode=clamping` and output limiting enabled. This is local PI clamping; no explicit tracking feedback from the external fuel/rate limiters is present. The report therefore does not claim robust anti-windup under every external saturation combination.

The release fixes clean-start initialization and logging only: all lookup/spool variables are passed explicitly through `Simulink.SimulationInput`, and scenario overrides/logging are in memory. The original `.slx` models and `datas.m` coefficients are unchanged. Red check before the new harness failed because a clean-start runner was absent; final runs need no manual base-workspace setup. During harness development, duplicate named signal branches and an incorrect multi-parameter `setBlockParameter` call were exposed by actual MATLAB runs and corrected before the passing full run.

Initial engine speed is inherited from the saved models, not a physical crank/start sequence. No altitude sweep, validated fuel units, calibrated engine data, real-engine test, physical safety qualification or full operating-envelope proof was performed. Suggested CV wording can remain “illustrative Simulink turbojet speed-control model with PI clamping, fuel schedules and rate limiting; demonstrated simulated RPM tracking and idle retention at zero throttle.” Rights to publish internship-related files remain undetermined; see `ATTRIBUTION.md`. No publishing, remote or hardware action occurred.

function results = run_all(artifact_dir)
% Initialise every lookup explicitly and log named signals in unsaved models.
if nargin<1,artifact_dir=fullfile(tempdir,'turbojet-release-results');end
if ~exist(artifact_dir,'dir'),mkdir(artifact_dir);end
root=fileparts(mfilename('fullpath'));
Simulink.fileGenControl('set','CacheFolder',fullfile(artifact_dir,'cache'), ...
 'CodeGenFolder',fullfile(artifact_dir,'codegen'),'createDir',true);
run(fullfile(root,'src','datas.m'));
variables={'actual_rpm_pts','delta_rpm_pts','decel_limit_fuel','accel_limit_fuel', ...
 'steady_state_fuel','throttle_pct','altitude_ft','target_rpm_map', ...
 'spool_kf','spool_k2','spool_k4','spool_n0'};
models={'override_n_feedfw_feedbk_ctrl','override_n_feedfw_feedbk_ctrl_torque_plant'};
for k=1:numel(models)
 if bdIsLoaded(models{k})
  error('release:ModelAlreadyLoaded','Close or save and close the already-open model %s before reproduction.',models{k});
 end
end
results.matlab_version=version;
for k=1:2
 mdl=models{k};load_system(fullfile(root,'src',[mdl '.slx']));
 cleanup=onCleanup(@()close_system(mdl,0));
 lines=find_system(mdl,'FindAll','on','SearchDepth',1,'Type','line');
 for j=1:numel(lines)
  name=get_param(lines(j),'Name');
  if isempty(name),continue,end
  src=get_param(lines(j),'SrcPortHandle');if src<0,continue,end
  blk=[mdl '/release_' name];
  if getSimulinkBlockHandle(blk)>0,continue,end
  add_block('simulink/Sinks/To Workspace',blk,'VariableName',name,'SaveFormat','Timeseries');
  ph=get_param(blk,'PortHandles');add_line(mdl,src,ph.Inport,'autorouting','on');
 end
 input=Simulink.SimulationInput(mdl);
 for j=1:numel(variables),input=input.setVariable(variables{j},eval(variables{j}));end
 input=input.setModelParameter('StopTime','90','MaxStep','0.01','RelTol','1e-7','ReturnWorkspaceOutputs','on');
 pid=find_system(mdl,'SearchDepth',1,'MaskType','PID 1dof');
 if isempty(pid),pid=find_system(mdl,'SearchDepth',1,'RegExp','on','Name','PI Fuel Flow Ctrl.*');end
 assert(strcmp(get_param(pid{1},'AntiWindupMode'),'clamping'),'PI anti-windup must remain enabled');
 results.(mdl).antiwindup='PI internal output clamping (not external limiter tracking)';
 for scenario=1:3
  names={'original_step','idle','full_to_idle'};name=names{scenario};
  trial=input;
  if scenario==2
   trial=trial.setBlockParameter([mdl '/Throttle'],'Before','0');
   trial=trial.setBlockParameter([mdl '/Throttle'],'After','0');
   trial=trial.setBlockParameter([mdl '/Throttle'],'Time','30');
  elseif scenario==3
   trial=trial.setBlockParameter([mdl '/Throttle'],'Before','100');
   trial=trial.setBlockParameter([mdl '/Throttle'],'After','0');
   trial=trial.setBlockParameter([mdl '/Throttle'],'Time','45');
  end
  fprintf('SIMULATING %s %s\n',mdl,name);out=sim(trial);
  rpm=out.rpm_actual;target=out.rpm_target;fuel=out.fuel_flow_target;
  results.(mdl).(name).final_rpm=rpm.Data(end);
  results.(mdl).(name).final_target=target.Data(end);
  results.(mdl).(name).final_error=abs(rpm.Data(end)-target.Data(end));
  results.(mdl).(name).fuel_min=min(fuel.Data);
  results.(mdl).(name).fuel_max=max(fuel.Data);
  actual=interp1(rpm.Time,rpm.Data,fuel.Time,'linear');
  upper=interp1(actual_rpm_pts,accel_limit_fuel,min(100,max(40,actual)));
  results.(mdl).(name).max_accel_limit_excess=max(fuel.Data-upper);
  assert(all(isfinite(rpm.Data)) && all(rpm.Data>=0),'Spool must remain finite and nonnegative');
  assert(min(fuel.Data)>=180-1e-6 && max(fuel.Data-upper)<1e-4,'Fuel schedules must bound target fuel');
  assert(results.(mdl).(name).final_error<1,'Steady-state tracking must be within 1 RPM percentage point');
  save(fullfile(artifact_dir,[mdl '_' name '.mat']),'out');
 end
 close_system(mdl,0);clear cleanup
end
fid=fopen(fullfile(artifact_dir,'results.json'),'w');fprintf(fid,'%s',jsonencode(results,PrettyPrint=true));fclose(fid);
fprintf('PASS: two plants, three scenarios each; fuel bounds, finite RPM, settled tracking, PI clamp\n');
end

function test_model_ownership
mdl='override_n_feedfw_feedbk_ctrl';other='turbo_unsaved_sentinel';
assert(~bdIsLoaded(mdl) && ~bdIsLoaded(other),'Close test model names first');
new_system(mdl);add_block('simulink/Sources/Constant',[mdl '/unsaved_work']);
new_system(other);add_block('simulink/Sources/Constant',[other '/unsaved_work']);
cleanup=onCleanup(@()close_owned({mdl,other}));
try,run_all;refused=false;catch err,refused=strcmp(err.identifier,'release:ModelAlreadyLoaded');end
assert(refused && bdIsLoaded(mdl) && getSimulinkBlockHandle([mdl '/unsaved_work'])>0, ...
 'Refusing a preloaded target must preserve its unsaved changes');
assert(bdIsLoaded(other),'Unrelated unsaved model must stay open');
fprintf('PASS: turbojet refuses preloaded targets and preserves unrelated models\n');
end
function close_owned(names)
for k=1:numel(names),if bdIsLoaded(names{k}),close_system(names{k},0);end,end
end

"""Run MATLAB in a temporary working directory with isolated preferences/cache."""
from pathlib import Path
import os, subprocess, tempfile
root=Path(__file__).resolve().parent
matlab=os.environ.get('MATLAB_BIN','/Applications/MATLAB_R2024b.app/bin/matlab')
def quote(path): return str(path).replace("'", "''")
with tempfile.TemporaryDirectory(prefix='matlab-release-') as scratch:
    env=os.environ.copy()
    env['MATLAB_PREFDIR']=str(Path(scratch)/'prefs')
    env['TMPDIR']=scratch
    result_dir=root/'results'
    expression="addpath('%s'); " % quote(root)
    expression+="addpath('%s'); test_model_ownership; " % quote(root/'tests')
    expression+="run_all('%s');" % quote(result_dir)
    subprocess.run([matlab,'-batch',expression],cwd=scratch,env=env,timeout=600,check=True)
