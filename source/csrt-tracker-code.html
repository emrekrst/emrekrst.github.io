# CSRT Camera Tracker

CPU-only object tracking with Qt 6, GStreamer and OpenCV. Click once to select a target; asynchronous CSRT updates use a latest-frame mailbox so busy tracking cannot build a queue of stale frames. Recorded video supports playback, seeking and reselection. The Raspberry Pi IMX477 source shares the same canvas and controller.

![Tracking a generated moving target](samples/tracking-demo.png)

## Build and test

Requires a C++20 compiler, CMake 3.24+, Qt 6.5+ (Core, Gui, Widgets, Test), OpenCV 4 with the tracking module, pkg-config, and GStreamer 1.20+ (core, app and video development libraries). The file tests need `videotestsrc`, JPEG/AVI, x264/H.264/MP4 encoders and decoders. On macOS `scripts/bootstrap-mac.sh` can install missing Homebrew dependencies when deliberately run; it was not used to install software during release preparation.

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
QT_QPA_PLATFORM=offscreen ctest --test-dir build --output-on-failure
```

On macOS:

```bash
./build/CameraTracker.app/Contents/MacOS/CameraTracker --open samples/moving-target.avi
```

On Linux use `./build/CameraTracker --open samples/moving-target.avi`. Click the red target near the left of the frame. Seeking resets selection. The bundled six-second sample is synthetic; `scripts/generate-sample.py` regenerates it using Python, NumPy and OpenCV. No external footage is distributed.

To reproduce the test screenshot:

```bash
QT_QPA_PLATFORM=offscreen CSRT_DEMO_SCREENSHOT="$PWD/samples/tracking-demo.png"   ./build/main_window_tests recordedDemoTracksMovingTarget
```

## Raspberry Pi

The checked-in camera profile requests 2028×1080, 50 FPS, 12-bit IMX477 frames. Configuration is in `config/camera-tracker.ini`; restart after editing camera or tracker parameters. Pi camera use needs Raspberry Pi OS, libcamera/GStreamer camera plugins and the physical sensor. It is disabled on macOS.

On the target Pi, `scripts/setup-rpi.sh`, `scripts/build-rpi.sh`, `scripts/diagnose-rpi.sh`, and `scripts/run-rpi.sh` provide the original setup/build/diagnostic workflow. Setup may install OS packages; diagnostics open the camera. SSH sync scripts require an explicit `RPI_TARGET=user@host` and accept `RPI_REMOTE_ROOT` (default `CameraTracker`, relative to the remote home). No deployment host is embedded in this copy.

See [VERIFICATION.md](VERIFICATION.md) for fresh desktop results and [historical hardware evidence](docs/HISTORICAL_EVIDENCE.md) for the inherited Pi baseline. Optuna tuning scripts and benchmark datasets were not recovered in this source copy; no new tuning result is claimed.

## Changes and regression evidence

- Added a generated recording, generated selector fixtures, generator script and recorded-video integration check. The new recording test failed before the sample existed and passed after generation.
- Replaced two inherited photographic road/car crops with generated PNG fixtures because the original media provenance was unknown. Their original regression checks passed during the initial local baseline; final public tests use clearly named generated-fixture cases. Real-photo generalization is therefore not established by the distributed fixtures.
- Removed embedded personal SSH/home paths. Sync requires `RPI_TARGET` and accepts `RPI_REMOTE_ROOT`; tests use fake SSH/rsync executables and verify abort-on-SSH-error and absence of deletion flags.
- Isolated the run-script default-environment test from the enclosing offscreen CTest environment. The failure was reproduced with `QT_QPA_PLATFORM=offscreen` before the test fix; production GUI/CSRT algorithms were unchanged.
- Excluded generated builds, private footage, agent plans and stale tuning instructions. Original source files were not edited.

#!/usr/bin/env bash

    echo "This bootstrap script is for macOS."
    exit 1

    echo "Homebrew is required: https://brew.sh"
    exit 1

for package in "${required[@]}"; do
    if ! brew list --versions "$package" >/dev/null 2>&1; then
        missing+=("$package")
    fi
done

if (( ${#missing[@]} > 0 )); then
    brew install "${missing[@]}"
fi

project_root="$(cd "$(dirname "$0")/.." && pwd)"
cmake -S "$project_root" -B "$project_root/build" -G Ninja \
    -DCMAKE_BUILD_TYPE=Debug \
    "-DCMAKE_PREFIX_PATH=$(brew --prefix qtbase);$(brew --prefix opencv@4)"
cmake --build "$project_root/build"

echo "Built: $project_root/build/CameraTracker.app"

#!/usr/bin/env bash
set -euo pipefail

echo "== Operating system =="
cat /etc/os-release
echo "== Architecture =="
uname -m
echo "== Memory =="
free -h
echo "== Root filesystem =="
df -h /
echo "== Temperature =="
vcgencmd measure_temp
echo "== Cameras =="
rpicam-hello --list-cameras
echo "== Package versions =="
dpkg-query -W \
    cmake qt6-base-dev qt6-wayland libopencv-dev \
    libgstreamer1.0-dev libgstreamer-plugins-base1.0-dev \
    gstreamer1.0-libcamera gstreamer1.0-plugins-ugly
echo "== Required GStreamer elements =="
for element in libcamerasrc glimagesink appsink x264enc; do
    gst-inspect-1.0 "$element" >/dev/null
    echo "$element: available"
done

echo "== Five-second IMX477 frame probe =="
probe_log="$(mktemp)"
trap 'rm -f "$probe_log"' EXIT
set +e
timeout 5s gst-launch-1.0 \
    libcamerasrc \
    sensor-config="sensor/config,width=2028,height=1080,depth=12" \
    ae-enable=true exposure-time-mode=manual exposure-time=5000 \
    analogue-gain-mode=auto ! \
    "video/x-raw,format=BGRx,width=2028,height=1080,framerate=50/1" ! \
    fakesink sync=false >"$probe_log" 2>&1
probe_status=$?
set -e
cat "$probe_log"

if [[ "$probe_status" -ne 124 ]]; then
    echo "Camera probe ended unexpectedly with status $probe_status." >&2
    exit 1
fi
if ! grep -Fq 'Setting pipeline to PLAYING' "$probe_log"; then
    echo "Camera probe never reached PLAYING." >&2
    exit 1
fi
if grep -Fq 'ERROR' "$probe_log"; then
    echo "Camera probe reported a GStreamer error." >&2
    exit 1
fi
echo "IMX477 frame probe passed."

#!/usr/bin/env python3
"""Generate the redistributable synthetic recorded-video fixture; no camera access."""
from pathlib import Path
import cv2
import numpy as np

path = Path(__file__).resolve().parents[1] / "samples/moving-target.avi"
path.parent.mkdir(exist_ok=True)
writer = cv2.VideoWriter(str(path), cv2.VideoWriter_fourcc(*"MJPG"), 10, (640, 360))
if not writer.isOpened():
    raise RuntimeError("MJPG VideoWriter unavailable")
for index in range(60):
    frame = np.full((360, 640, 3), (130, 145, 160), dtype=np.uint8)
    x = 80 + 2 * index
    cv2.rectangle(frame, (x, 120), (x + 47, 147), (35, 75, 205), -1)
    cv2.rectangle(frame, (x, 120), (x + 47, 147), (10, 20, 40), 2)
    cv2.circle(frame, (x + 24, 134), 4, (50, 90, 220), -1)
    writer.write(frame)
writer.release()
print(path)

# File-backed selector regressions use generated imagery, not private video crops.
fixtures = path.parents[1] / "tests/fixtures"
fixtures.mkdir(exist_ok=True)
road = np.full((320, 320, 3), (118, 122, 126), dtype=np.uint8)
cv2.rectangle(road, (100, 100), (220, 220), (76, 79, 82), 3)
car = np.full((320, 320, 3), (140, 145, 150), dtype=np.uint8)
cv2.rectangle(car, (134, 146), (188, 174), (35, 70, 200), -1)
cv2.rectangle(car, (134, 146), (188, 174), (10, 20, 40), 2)
cv2.rectangle(car, (145, 149), (177, 154), (60, 75, 90), -1)
for name, frame in [("road-click.png", road), ("car-click.png", car)]:
    if not cv2.imwrite(str(fixtures / name), frame):
        raise RuntimeError(f"could not write {name}")

#!/usr/bin/env bash
set -euo pipefail

if [[ "$(uname -m)" != "aarch64" ]]; then
    echo "This setup supports Raspberry Pi OS aarch64 only." >&2
    exit 1
fi
if [[ ! -f /etc/rpi-issue ]]; then
    echo "This does not appear to be Raspberry Pi OS." >&2
    exit 1
fi

# shellcheck disable=SC1091
source /etc/os-release
if [[ "${VERSION_CODENAME:-}" != "trixie" ]]; then
    echo "Expected Raspberry Pi OS Trixie; found ${PRETTY_NAME:-unknown}." >&2
    exit 1
fi

camera_list="$(rpicam-hello --list-cameras 2>&1)"
if ! grep -qi 'imx477' <<<"$camera_list"; then
    echo "IMX477 was not found by rpicam-hello." >&2
    exit 1
fi

packages=(
    cmake
    ninja-build
    pkg-config
    qt6-base-dev
    qt6-wayland
    libopencv-dev
    libgstreamer1.0-dev
    libgstreamer-plugins-base1.0-dev
    gstreamer1.0-libcamera
    gstreamer1.0-plugins-ugly
    rsync
)
missing=()
for package in "${packages[@]}"; do
    if ! dpkg-query -W -f='${Status}' "$package" 2>/dev/null \
        | grep -q 'install ok installed'; then
        missing+=("$package")
    fi
done

if (( ${#missing[@]} > 0 )); then
    sudo apt-get update
    sudo apt-get install -y "${missing[@]}"
else

CameraConfigResult invalidSetting(const QString& key, const QString& value,
                                  const QString& expected)

bool readPositiveInteger(QSettings& settings, const QString& key, int& output,
                         CameraConfigResult& error)
{
    if (!settings.contains(key)) {
        error = invalidSetting(key, QStringLiteral("<missing>"),
                               QStringLiteral("a positive integer"));
        return false;
    }

    const QString value = settings.value(key).toString();
    bool ok = false;
    const int parsed = value.toInt(&ok);
    if (!ok || parsed <= 0) {
        error = invalidSetting(key, value, QStringLiteral("a positive integer"));
        return false;
    }
    output = parsed;
    return true;
}

bool readBoolean(QSettings& settings, const QString& key, bool& output,
                 CameraConfigResult& error)
{
    if (!settings.contains(key)) {
        error = invalidSetting(key, QStringLiteral("<missing>"),
                               QStringLiteral("true or false"));
        return false;
    }

    const QString value = settings.value(key).toString();
    if (value == QStringLiteral("true")) {
        output = true;
        return true;
    }
    if (value == QStringLiteral("false")) {
        output = false;
        return true;
    }
    error = invalidSetting(key, value, QStringLiteral("true or false"));
    return false;
}

bool readIntegerInRange(QSettings& settings, const QString& key, int minimum,
                        int maximum, int& output, CameraConfigResult& error)
{
    if (!settings.contains(key)) {
        error = invalidSetting(key, QStringLiteral("<missing>"),
                               QStringLiteral("an integer in [%1, %2]")
                                   .arg(minimum)
                                   .arg(maximum));
        return false;
    }

    const QString value = settings.value(key).toString();
    bool ok = false;
    const int parsed = value.toInt(&ok);
    if (!ok || parsed < minimum || parsed > maximum) {
        error = invalidSetting(key, value,
                               QStringLiteral("an integer in [%1, %2]")
                                   .arg(minimum)
                                   .arg(maximum));
        return false;
    }
    output = parsed;
    return true;
}

bool readFloatInRange(QSettings& settings, const QString& key, float minimum,
                      float maximum, bool minimumInclusive, const QString& acceptedRange,
                      float& output,
                      CameraConfigResult& error)
{
    if (!settings.contains(key)) {
        error = invalidSetting(key, QStringLiteral("<missing>"),
                               QStringLiteral("a number in %1").arg(acceptedRange));
        return false;
    }

    const QString value = settings.value(key).toString();
    bool ok = false;
    const float parsed = value.toFloat(&ok);
    if (!ok || !std::isfinite(parsed)
        || (minimumInclusive ? parsed < minimum : parsed <= minimum)
        || parsed > maximum) {
        error = invalidSetting(key, value,
                               QStringLiteral("a number in %1").arg(acceptedRange));
        return false;
    }
    output = parsed;
    return true;
}

bool readTrackingConfig(QSettings& settings, CsrtConfig& config,
                        CameraConfigResult& error)
{
    if (!settings.childGroups().contains(QStringLiteral("tracking"))) {
        return true;
    }

    settings.beginGroup(QStringLiteral("tracking"));
    const bool valid =
        readBoolean(settings, QStringLiteral("use_hog"), config.useHog, error)
        && readBoolean(settings, QStringLiteral("use_color_names"), config.useColorNames, error)
        && readBoolean(settings, QStringLiteral("use_gray"), config.useGray, error)
        && readBoolean(settings, QStringLiteral("use_rgb"), config.useRgb, error)
        && readBoolean(settings, QStringLiteral("use_channel_weights"), config.useChannelWeights, error)
        && readBoolean(settings, QStringLiteral("use_segmentation"), config.useSegmentation, error)
        && readFloatInRange(settings, QStringLiteral("template_size"), 16.0F, 2048.0F,
                            true, QStringLiteral("[16, 2048]"), config.templateSize, error)
        && readFloatInRange(settings, QStringLiteral("padding"), 0.0F, 10.0F,
                            false, QStringLiteral("(0, 10]"), config.padding, error)
        && readIntegerInRange(settings, QStringLiteral("number_of_scales"), 1, 101,
                              config.numberOfScales, error)
        && readFloatInRange(settings, QStringLiteral("scale_step"), 1.0F, 1.5F,
                            false, QStringLiteral("(1, 1.5]"), config.scaleStep, error)
        && readIntegerInRange(settings, QStringLiteral("admm_iterations"), 1, 20,
                              config.admmIterations, error)
        && readFloatInRange(settings, QStringLiteral("psr_threshold"), 0.0F, 1.0F,
                            true, QStringLiteral("[0, 1]"), config.psrThreshold, error);
    settings.endGroup();
    return valid;
}

CameraConfigResult loadCameraConfig(const QString& path)
{
    const QFileInfo file(path);
    const QString absolutePath = file.absoluteFilePath();
    if (!file.isFile()) {
        return {std::nullopt,
                QStringLiteral("Camera configuration file not found: %1")
                    .arg(absolutePath)};
    }

    QSettings settings(absolutePath, QSettings::IniFormat);
    settings.beginGroup(QStringLiteral("camera"));

    CameraConfig config;
    CameraConfigResult error;
    if (!readPositiveInteger(settings, QStringLiteral("width"), config.width, error)
        || !readPositiveInteger(settings, QStringLiteral("height"), config.height, error)
        || !readPositiveInteger(settings, QStringLiteral("fps"), config.fps, error)) {
        return error;
    }

    const QString depthValue = settings.value(QStringLiteral("sensor_depth")).toString();
    bool depthOk = false;
    const int depth = depthValue.toInt(&depthOk);
    if (!settings.contains(QStringLiteral("sensor_depth")) || !depthOk
        || (depth != 8 && depth != 10 && depth != 12)) {
        return invalidSetting(QStringLiteral("sensor_depth"),
                              settings.contains(QStringLiteral("sensor_depth"))
                                  ? depthValue : QStringLiteral("<missing>"),
                              QStringLiteral("8, 10, or 12"));
    }
    config.sensorDepth = depth;

    if (!readPositiveInteger(settings, QStringLiteral("exposure_us"),
                             config.exposureMicroseconds, error)) {
        return error;
    }

    const QString gainMode = settings.value(QStringLiteral("gain_mode")).toString();
    if (!settings.contains(QStringLiteral("gain_mode"))) {
        return invalidSetting(QStringLiteral("gain_mode"), QStringLiteral("<missing>"),
                              QStringLiteral("auto or manual"));
    }
    if (gainMode == QStringLiteral("auto")) {
        config.gainMode = CameraGainMode::Auto;
    } else if (gainMode == QStringLiteral("manual")) {
        config.gainMode = CameraGainMode::Manual;
    } else {
        return invalidSetting(QStringLiteral("gain_mode"), gainMode,
                              QStringLiteral("auto or manual"));
    }

    const QString gainValue = settings.value(QStringLiteral("analogue_gain")).toString();
    bool gainOk = false;
    const double gain = gainValue.toDouble(&gainOk);
    if (!settings.contains(QStringLiteral("analogue_gain")) || !gainOk || gain < 1.0) {
        return invalidSetting(QStringLiteral("analogue_gain"),
                              settings.contains(QStringLiteral("analogue_gain"))
                                  ? gainValue : QStringLiteral("<missing>"),
                              QStringLiteral("a number greater than or equal to 1.0"));
    }
    config.analogueGain = gain;

    settings.endGroup();
    if (!readTrackingConfig(settings, config.tracking, error)) {
        return error;
    }

    return {config, {}};
}

namespace {
quint64 nonDecreasingDelta(quint64 current, quint64 previous) noexcept
{
    return current >= previous ? current - previous : 0;
}

double ratePerSecond(quint64 count, qint64 milliseconds) noexcept
{
    return milliseconds > 0 ? static_cast<double>(count) * 1000.0 / milliseconds : 0.0;
}

QString formattedMilliseconds(double milliseconds)
{
    return QString::number(qRound64(std::max(0.0, milliseconds)));
}
} // namespace

RuntimeRates RuntimeTelemetrySampler::sample(
    const RuntimeTotals& totals,
    qint64 monotonicMilliseconds)
{
    if (!hasBaseline_) {
        previousTotals_ = totals;
        previousMilliseconds_ = monotonicMilliseconds;
        hasBaseline_ = true;
        return {};
    }

    const qint64 elapsedMilliseconds = monotonicMilliseconds - previousMilliseconds_;
    if (elapsedMilliseconds <= 0) {
        return {};
    }

    const quint64 cameraFrames = nonDecreasingDelta(totals.cameraFrames, previousTotals_.cameraFrames);
    const quint64 displayedFrames = nonDecreasingDelta(
        totals.displayedFrames, previousTotals_.displayedFrames);
    const quint64 completedUpdates = nonDecreasingDelta(
        totals.completedUpdates, previousTotals_.completedUpdates);
    const quint64 skippedFrames = nonDecreasingDelta(
        totals.skippedFrames, previousTotals_.skippedFrames);

    previousTotals_ = totals;
    previousMilliseconds_ = monotonicMilliseconds;

    RuntimeRates rates;
    rates.cameraFps = ratePerSecond(cameraFrames, elapsedMilliseconds);
    rates.viewFps = ratePerSecond(displayedFrames, elapsedMilliseconds);
    rates.trackingFps = ratePerSecond(completedUpdates, elapsedMilliseconds);
    const quint64 trackingFrames = completedUpdates + skippedFrames;
    rates.skipPercent = trackingFrames == 0
        ? 0.0
        : static_cast<double>(skippedFrames) * 100.0 / trackingFrames;
    rates.lastUpdateMilliseconds = totals.lastUpdateMilliseconds;
    rates.lastResultAgeMilliseconds = totals.lastResultAgeMilliseconds;
    rates.trackingActive = totals.trackingActive;
    return rates;
}

void RuntimeTelemetrySampler::reset() noexcept
{
    previousTotals_ = {};
    previousMilliseconds_ = 0;
    hasBaseline_ = false;
}

QString formatRuntimeTelemetry(const RuntimeRates& rates)
{
    const QString camera = QString::number(rates.cameraFps, 'f', 1);
    const QString view = QString::number(rates.viewFps, 'f', 1);
    if (!rates.trackingActive) {
        return QStringLiteral("CAM %1 | VIEW %2 | TRACK -- | CSRT -- | AGE -- | SKIP --")
            .arg(camera, view);
    }

    return QStringLiteral("CAM %1 | VIEW %2 | TRACK %3 | CSRT %4 ms | AGE %5 ms | SKIP %6%")
        .arg(camera)
        .arg(view)
        .arg(QString::number(rates.trackingFps, 'f', 1))
        .arg(formattedMilliseconds(rates.lastUpdateMilliseconds))
        .arg(formattedMilliseconds(rates.lastResultAgeMilliseconds))
        .arg(QString::number(qRound64(std::clamp(rates.skipPercent, 0.0, 100.0))));
}

bool AbstractPipeline::adoptAndPlay(
    GstElement* pipeline,
    GstElement* videoSink,
    GstElement* trackerQueue,
    WId windowHandle)
{
    stop();
    if (pipeline == nullptr || videoSink == nullptr) {
        if (pipeline != nullptr) {
            gst_object_unref(pipeline);
        }
        reportError("GStreamer could not create the playback pipeline.");
        return false;
    }

    pipeline_ = pipeline;
    videoSink_ = GST_ELEMENT(gst_object_ref(videoSink));
    bus_ = gst_element_get_bus(pipeline_);

    if (windowHandle != 0 && GST_IS_VIDEO_OVERLAY(videoSink_)) {
        gst_video_overlay_set_window_handle(
            GST_VIDEO_OVERLAY(videoSink_),
            static_cast<guintptr>(windowHandle));
    }

    if (trackerQueue != nullptr) {
        probePad_ = gst_element_get_static_pad(trackerQueue, "src");
        if (probePad_ != nullptr) {
            probeId_ = gst_pad_add_probe(
                probePad_,
                GST_PAD_PROBE_TYPE_BUFFER,
                &AbstractPipeline::bufferProbe,
                this,
                nullptr);
        }
    }

    const GstStateChangeReturn stateResult =
        gst_element_set_state(pipeline_, GST_STATE_PLAYING);
    if (stateResult == GST_STATE_CHANGE_FAILURE) {
        reportError("GStreamer could not start playback.");
        stop();
        return false;
    }

    busTimer_.start();
    return true;
}

void AbstractPipeline::stop()
{
    busTimer_.stop();
    detachProbe();
    if (pipeline_ != nullptr) {
        gst_element_set_state(pipeline_, GST_STATE_NULL);
    }
    if (bus_ != nullptr) {
        gst_object_unref(bus_);
        bus_ = nullptr;
    }
    if (videoSink_ != nullptr) {
        gst_object_unref(videoSink_);
        videoSink_ = nullptr;
    }
    if (pipeline_ != nullptr) {
        gst_object_unref(pipeline_);
        pipeline_ = nullptr;
    }
    observedFrames_.store(0, std::memory_order_relaxed);
    frameSize_ = {};
}

bool AbstractPipeline::seek(double normalizedPosition)
{
    if (pipeline_ == nullptr || normalizedPosition < 0.0 || normalizedPosition > 1.0) {
        return false;

    const qint64 duration = durationMilliseconds();
    if (duration <= 0) {

        pipeline_,
        GST_FORMAT_TIME,
        static_cast<GstSeekFlags>(GST_SEEK_FLAG_FLUSH | GST_SEEK_FLAG_ACCURATE),
        target);
}

void AbstractPipeline::pollBus()
{
    if (bus_ == nullptr) {
        return;
    }

    while (GstMessage* message = gst_bus_pop_filtered(
               bus_, static_cast<GstMessageType>(GST_MESSAGE_ERROR | GST_MESSAGE_EOS))) {
        if (GST_MESSAGE_TYPE(message) == GST_MESSAGE_ERROR) {
            GError* error = nullptr;
            gchar* details = nullptr;
            gst_message_parse_error(message, &error, &details);
            const QString text = error != nullptr
                ? QString::fromUtf8(error->message)
                : QStringLiteral("Unknown GStreamer error");
            g_clear_error(&error);
            g_free(details);
            gst_message_unref(message);
            reportError(text);
            stop();
            return;
        }

        gst_message_unref(message);
        emit endOfStream();
        setPaused(true);
    }
}

GstPadProbeReturn AbstractPipeline::bufferProbe(
    GstPad* pad,
    GstPadProbeInfo* info,
    gpointer userData)
{
    auto* self = static_cast<AbstractPipeline*>(userData);
    self->observedFrames_.fetch_add(1, std::memory_order_relaxed);
    GstCaps* caps = gst_pad_get_current_caps(pad);
    if (caps != nullptr && !gst_caps_is_empty(caps)) {
        if (auto* sink = self->trackingFrameSink_.load(std::memory_order_acquire)) {
            GstVideoInfo videoInfo;
            if (gst_video_info_from_caps(&videoInfo, caps)) {
                sink->offerFrame(gst_pad_probe_info_get_buffer(info), videoInfo);
            }
        }
        const GstStructure* structure = gst_caps_get_structure(caps, 0);
        int width = 0;
        int height = 0;
        if (gst_structure_get_int(structure, "width", &width)
            && gst_structure_get_int(structure, "height", &height)) {
            const QSize nextSize(width, height);
            if (nextSize != self->frameSize_) {
                self->frameSize_ = nextSize;
                QMetaObject::invokeMethod(
                    self,
                    [self, nextSize] { emit self->frameSizeChanged(nextSize); },
                    Qt::QueuedConnection);
            }
        }
        gst_caps_unref(caps);
    }
    return GST_PAD_PROBE_OK;
}

void AbstractPipeline::detachProbe()
{
    if (probePad_ != nullptr) {
        if (probeId_ != 0) {
            gst_pad_remove_probe(probePad_, probeId_);
        }
        gst_object_unref(probePad_);
        probePad_ = nullptr;
        probeId_ = 0;
    }
}

bool CameraPipeline::start(WId windowHandle, const CameraConfig& config)
{
    Q_UNUSED(windowHandle)
    if (!isAvailable()) {
        reportError(unavailabilityReason());
        return false;
    }

    GError* parseError = nullptr;
    GstElement* pipeline = gst_parse_launch(description(config).toUtf8().constData(), &parseError);
    if (pipeline == nullptr) {
        const QString message = parseError != nullptr
            ? QString::fromUtf8(parseError->message)
            : QStringLiteral("Could not parse the camera pipeline.");
        g_clear_error(&parseError);
        reportError(message);
        return false;
    }

    GstElement* sink = gst_bin_get_by_name(GST_BIN(pipeline), "video_sink");
    GstElement* queue = gst_bin_get_by_name(GST_BIN(pipeline), "tracker_queue");
    if (sink != nullptr) {
        g_signal_connect(sink, "new-sample", G_CALLBACK(&CameraPipeline::newSample), this);
        g_signal_connect(sink, "new-preroll", G_CALLBACK(&CameraPipeline::newPreroll), this);
    }
    const bool started = adoptAndPlay(pipeline, sink, queue, 0);
    if (sink != nullptr) {
        gst_object_unref(sink);
    }
    if (queue != nullptr) {
        gst_object_unref(queue);
    }
    return started;
}

GstFlowReturn CameraPipeline::deliverSample(GstSample* sample)
{
    if (sample == nullptr) {
        return GST_FLOW_OK;
    }

    {
        std::lock_guard lock(frameMutex_);
        if (deliveryPosted_) {
            gst_sample_unref(sample);
            return GST_FLOW_OK;
        }
        deliveryPosted_ = true;
    }

    GstCaps* caps = gst_sample_get_caps(sample);
    GstBuffer* buffer = gst_sample_get_buffer(sample);
    GstVideoInfo info;
    if (caps == nullptr || buffer == nullptr || !gst_video_info_from_caps(&info, caps)) {
        gst_sample_unref(sample);
        releaseDeliverySlot();
        return GST_FLOW_OK;
    }

    GstVideoFrame videoFrame;
    if (!gst_video_frame_map(&videoFrame, &info, buffer, GST_MAP_READ)) {
        gst_sample_unref(sample);
        releaseDeliverySlot();
        return GST_FLOW_OK;
    }

    const int width = GST_VIDEO_FRAME_WIDTH(&videoFrame);
    const int height = GST_VIDEO_FRAME_HEIGHT(&videoFrame);
    const int stride = GST_VIDEO_FRAME_PLANE_STRIDE(&videoFrame, 0);
    const QImage wrapped(
        static_cast<const uchar*>(GST_VIDEO_FRAME_PLANE_DATA(&videoFrame, 0)),
        width, height, stride, QImage::Format_RGB32);
    const QSize target = QSize(width, height).scaled(
        std::max(1, displayWidth_.load()),
        std::max(1, displayHeight_.load()),
        Qt::KeepAspectRatio);
    QImage scaled = wrapped.scaled(target, Qt::IgnoreAspectRatio, Qt::FastTransformation);
    if (scaled.constBits() == wrapped.constBits()) {
        scaled = wrapped.copy();
    }

    gst_video_frame_unmap(&videoFrame);
    gst_sample_unref(sample);

    {
        std::lock_guard lock(frameMutex_);
        pendingFrame_ = std::move(scaled);
    }
    QMetaObject::invokeMethod(
        this, [this] { deliverPendingFrame(); }, Qt::QueuedConnection);
    return GST_FLOW_OK;
}

void CameraPipeline::deliverPendingFrame()
{
    QImage frame;
    {
        std::lock_guard lock(frameMutex_);
        frame = std::move(pendingFrame_);
        deliveryPosted_ = false;
    }
    if (!frame.isNull()) {
        emit frameReady(frame);
    }
}

void CameraPipeline::releaseDeliverySlot()
{
    std::lock_guard lock(frameMutex_);
    deliveryPosted_ = false;
}

bool FilePipeline::open(const QString& filePath)
{
    stop();
    const QFileInfo file(filePath);
    if (!file.exists() || !file.isFile()) {
        reportError(QStringLiteral("The selected video file does not exist."));
        return false;
    }

    GstElement* pipeline = gst_pipeline_new("file_pipeline");
    GstElement* source = gst_element_factory_make("filesrc", "source");
    GstElement* decoder = gst_element_factory_make("decodebin", "decoder");
    GstElement* converter = gst_element_factory_make("videoconvert", "converter");
    GstElement* scaler = gst_element_factory_make("videoscale", "tracking_scaler");
    GstElement* capsFilter = gst_element_factory_make("capsfilter", "bgrx_caps");
    GstElement* queue = gst_element_factory_make("queue", "tracker_queue");
    GstElement* sink = gst_element_factory_make("appsink", "video_sink");

    if (pipeline == nullptr || source == nullptr || decoder == nullptr
        || converter == nullptr || scaler == nullptr || capsFilter == nullptr || queue == nullptr
        || sink == nullptr) {
        if (pipeline != nullptr) {
            gst_object_unref(pipeline);
        }
        reportError("A required GStreamer playback element is unavailable.");
        return false;
    }

    g_object_set(source, "location", file.absoluteFilePath().toUtf8().constData(), nullptr);
    g_object_set(queue,
        "max-size-buffers", 1,
        "max-size-bytes", 0,
        "max-size-time", static_cast<guint64>(0),
        "leaky", 0 /* no frame loss; backpressure at the media clock */,
        nullptr);

    // sync=true plays at the media's own rate; drop+max-buffers keep only
    // the newest frame so a slow UI can never stall the pipeline.
    g_object_set(sink,
        "emit-signals", TRUE,
        "sync", TRUE,
        "max-buffers", 1,
        "drop", TRUE,
        nullptr);

    GstCaps* caps = gst_caps_from_string(
        "video/x-raw,format=BGRx,width=(int)[1,1920],height=(int)[1,1080],pixel-aspect-ratio=1/1");
    g_object_set(capsFilter, "caps", caps, nullptr);
    g_object_set(sink, "caps", caps, nullptr);
    gst_caps_unref(caps);

    gst_bin_add_many(
        GST_BIN(pipeline), source, decoder, converter, scaler, capsFilter, queue, sink, nullptr);
    if (!gst_element_link(source, decoder)
        || !gst_element_link_many(converter, scaler, capsFilter, queue, sink, nullptr)) {
        gst_object_unref(pipeline);
        reportError("GStreamer could not link the file playback elements.");
        return false;
    }

    g_signal_connect(decoder, "pad-added", G_CALLBACK(&FilePipeline::padAdded), converter);
    g_signal_connect(sink, "new-sample", G_CALLBACK(&FilePipeline::newSample), this);
    g_signal_connect(sink, "new-preroll", G_CALLBACK(&FilePipeline::newPreroll), this);

    // No window handle: nothing is embedded, Qt paints the frames.
    return adoptAndPlay(pipeline, sink, queue, 0);
}

GstFlowReturn FilePipeline::deliverSample(GstSample* sample)
{
    if (sample == nullptr) {
        return GST_FLOW_OK;
    }

    GstCaps* caps = gst_sample_get_caps(sample);
    GstBuffer* buffer = gst_sample_get_buffer(sample);
    GstVideoInfo info;

    if (caps == nullptr || buffer == nullptr || !gst_video_info_from_caps(&info, caps)) {
        gst_sample_unref(sample);
        return GST_FLOW_OK;
    }

    GstVideoFrame videoFrame;
    if (!gst_video_frame_map(&videoFrame, &info, buffer, GST_MAP_READ)) {
        gst_sample_unref(sample);
        return GST_FLOW_OK;
    }

    const int width = GST_VIDEO_FRAME_WIDTH(&videoFrame);
    const int height = GST_VIDEO_FRAME_HEIGHT(&videoFrame);
    const int stride = GST_VIDEO_FRAME_PLANE_STRIDE(&videoFrame, 0);

    // BGRx byte order matches QImage::Format_RGB32 on little-endian, so
    // this wraps the mapped memory without copying it.
    const QImage wrapped(
        static_cast<const uchar*>(GST_VIDEO_FRAME_PLANE_DATA(&videoFrame, 0)),
        width, height, stride, QImage::Format_RGB32);

    // Scale here, on the streaming thread, so the UI thread never handles
    // a full-resolution frame. The result owns its own memory.
    const QSize target = QSize(width, height).scaled(
        std::max(1, displayWidth_.load()),
        std::max(1, displayHeight_.load()),
        Qt::KeepAspectRatio);
    QImage scaled = wrapped.scaled(target, Qt::IgnoreAspectRatio, Qt::SmoothTransformation);
    if (scaled.constBits() == wrapped.constBits()) {
        scaled = wrapped.copy();
    }

    gst_video_frame_unmap(&videoFrame);
    gst_sample_unref(sample);

    bool needsPost = false;
    {
        std::lock_guard lock(frameMutex_);
        pendingFrame_ = scaled;
        needsPost = !deliveryPosted_;
        deliveryPosted_ = true;
    }

    // Coalesce: only one delivery is ever queued, so a slow UI thread
    // drops intermediate frames instead of accumulating a backlog.
    if (needsPost) {
        QMetaObject::invokeMethod(
            this, [this] { deliverPendingFrame(); }, Qt::QueuedConnection);
    }

    return GST_FLOW_OK;
}

void FilePipeline::deliverPendingFrame()
{
    QImage frame;
    {
        std::lock_guard lock(frameMutex_);
        frame = pendingFrame_;
        pendingFrame_ = QImage();
        deliveryPosted_ = false;
    }

    if (!frame.isNull()) {
        emit frameReady(frame);
    }
}

void FilePipeline::padAdded(GstElement*, GstPad* newPad, gpointer userData)
{
    auto* converter = GST_ELEMENT(userData);
    GstPad* sinkPad = gst_element_get_static_pad(converter, "sink");
    if (gst_pad_is_linked(sinkPad)) {
        gst_object_unref(sinkPad);
        return;
    }

    GstCaps* caps = gst_pad_get_current_caps(newPad);
    if (caps == nullptr) {
        caps = gst_pad_query_caps(newPad, nullptr);
    }

    const GstStructure* structure = caps != nullptr && !gst_caps_is_empty(caps)
        ? gst_caps_get_structure(caps, 0)
        : nullptr;
    const char* mediaType = structure != nullptr ? gst_structure_get_name(structure) : "";
    if (g_str_has_prefix(mediaType, "video/")) {
        gst_pad_link(newPad, sinkPad);
    }
    if (caps != nullptr) {
        gst_caps_unref(caps);
    }
    gst_object_unref(sinkPad);
}

std::optional<cv::Rect> clampedRect(const FrameRect& box, const cv::Size& size)
{
    if (!std::isfinite(box.x) || !std::isfinite(box.y)
        || !std::isfinite(box.width) || !std::isfinite(box.height)
        || box.width < 2.0 || box.height < 2.0) {
        return std::nullopt;
    }

    const int left = std::clamp(cvRound(box.x), 0, size.width);
    const int top = std::clamp(cvRound(box.y), 0, size.height);
    const int right = std::clamp(cvRound(box.x + box.width), 0, size.width);
    const int bottom = std::clamp(cvRound(box.y + box.height), 0, size.height);
    if (right - left < 2 || bottom - top < 2) {
        return std::nullopt;
    }
    return cv::Rect(left, top, right - left, bottom - top);
}

bool CsrtTracker::initialize(const cv::Mat& bgrFrame, const FrameRect& box)
{
    reset();
    if (bgrFrame.empty()) {
        return false;
    }
    const auto roi = clampedRect(box, bgrFrame.size());
    if (!roi) {
        return false;
    }

    try {
        tracker_ = cv::TrackerCSRT::create(buildOpenCvCsrtParams(config_));
        tracker_->init(bgrFrame, *roi);
        box_ = toFrameRect(*roi);
        return true;
    } catch (const cv::Exception&) {
        reset();
        return false;
    }
}

std::optional<FrameRect> CsrtTracker::update(const cv::Mat& bgrFrame)
{
    if (!tracker_ || bgrFrame.empty()) {
        return std::nullopt;
    }

    try {
        cv::Rect updated;
        if (!tracker_->update(bgrFrame, updated)) {
            box_.reset();
            return std::nullopt;
        }
        const auto valid = clampedRect(toFrameRect(updated), bgrFrame.size());
        if (!valid) {
            box_.reset();
            return std::nullopt;
        }
        box_ = toFrameRect(*valid);
        return box_;
    } catch (const cv::Exception&) {
        box_.reset();
        return std::nullopt;
    }
}

void CsrtTracker::reset()
{
    tracker_.release();
    box_.reset();
}

    return box_;
}

void FrameMailbox::push(GstBuffer* buffer)
{
    if (buffer == nullptr) {
        return;
    }

    GstBuffer* replacement = gst_buffer_ref(buffer);
    {
        std::lock_guard lock(mutex_);
        if (stopped_) {
            gst_buffer_unref(replacement);
            return;
        }
        if (buffer_ != nullptr) {
            gst_buffer_unref(buffer_);
        }
        buffer_ = replacement;
    }
    ready_.notify_one();
}

GstBuffer* FrameMailbox::waitAndTake()
{
    std::unique_lock lock(mutex_);
    ready_.wait(lock, [this] { return stopped_ || buffer_ != nullptr; });
    if (buffer_ == nullptr) {
        return nullptr;
    }

    GstBuffer* result = buffer_;
    buffer_ = nullptr;
    return result;
}

void FrameMailbox::stop()
{
    {
        std::lock_guard lock(mutex_);
        stopped_ = true;
        if (buffer_ != nullptr) {
            gst_buffer_unref(buffer_);
            buffer_ = nullptr;
        }
    }
    ready_.notify_all();
}

#include <algorithm>
#include <array>
#include <cmath>
#include <vector>

#include <opencv2/imgproc.hpp>

namespace {

struct Candidate
{
    cv::Rect box;
    double confidence{};
};

cv::Rect clippedWindow(const cv::Point& centre, int radius, const cv::Size& bounds)
{
    const int left = std::max(0, centre.x - radius);
    const int top = std::max(0, centre.y - radius);
    const int right = std::min(bounds.width, centre.x + radius + 1);
    const int bottom = std::min(bounds.height, centre.y + radius + 1);
    return {left, top, right - left, bottom - top};
}

std::optional<Candidate> candidateAtScale(
    const cv::Mat& bgr,
    const cv::Point& click,
    int radius)
{
    const cv::Rect window = clippedWindow(click, radius, bgr.size());
    if (window.width < 9 || window.height < 9) {
        return std::nullopt;
    }

    const cv::Mat crop = bgr(window);
    cv::Scalar mean;
    cv::Scalar deviation;
    cv::meanStdDev(crop, mean, deviation);
    if (deviation[0] + deviation[1] + deviation[2] < 9.0) {
        return std::nullopt;
    }

    cv::Mat lab;
    cv::cvtColor(crop, lab, cv::COLOR_BGR2Lab);
    const cv::Point localClick(click.x - window.x, click.y - window.y);
    const cv::Rect seedRect = clippedWindow(localClick, 2, crop.size());
    const cv::Scalar seed = cv::mean(lab(seedRect));

    cv::Mat similar;
    cv::inRange(
        lab,
        cv::Scalar(seed[0] - 28.0, seed[1] - 22.0, seed[2] - 22.0),
        cv::Scalar(seed[0] + 28.0, seed[1] + 22.0, seed[2] + 22.0),
        similar);

    cv::Mat edges;
    cv::Canny(crop, edges, 35.0, 105.0);
    cv::dilate(edges, edges, cv::Mat(), {-1, -1}, 1);
    similar.setTo(0, edges);
    similar(seedRect).setTo(255);

    cv::Mat labels;
    cv::Mat stats;
    cv::Mat centroids;
    const int count = cv::connectedComponentsWithStats(similar, labels, stats, centroids, 8);
    if (count <= 1) {
        return std::nullopt;
    }

    const int label = labels.at<int>(localClick);
    if (label <= 0) {
        return std::nullopt;
    }

    const int area = stats.at<int>(label, cv::CC_STAT_AREA);
    const int cropArea = crop.rows * crop.cols;
    if (area < 10 || area > cropArea * 0.35) {
        return std::nullopt;
    }

    cv::Rect box(
        stats.at<int>(label, cv::CC_STAT_LEFT),
        stats.at<int>(label, cv::CC_STAT_TOP),
        stats.at<int>(label, cv::CC_STAT_WIDTH),
        stats.at<int>(label, cv::CC_STAT_HEIGHT));

    cv::Mat componentMask;
    cv::compare(labels, label, componentMask, cv::CMP_EQ);
    cv::Mat expanded;
    cv::Mat contextGap;
    cv::dilate(componentMask, expanded,
               cv::getStructuringElement(cv::MORPH_ELLIPSE, {33, 33}));
    cv::dilate(componentMask, contextGap,
               cv::getStructuringElement(cv::MORPH_ELLIPSE, {15, 15}));
    cv::Mat ring;
    cv::subtract(expanded, contextGap, ring);
    ring.setTo(0, edges);
    if (cv::countNonZero(ring) < 12) {
        return std::nullopt;
    }

    const cv::Scalar componentMean = cv::mean(lab, componentMask);
    const cv::Scalar ringMean = cv::mean(lab, ring);
    const double l = componentMean[0] - ringMean[0];
    const double a = componentMean[1] - ringMean[1];
    const double b = componentMean[2] - ringMean[2];
    const double colourSeparation = std::sqrt(l * l + a * a + b * b);
    if (colourSeparation < 11.0) {
        return std::nullopt;
    }

    if (box.x == 0 || box.y == 0 || box.br().x >= crop.cols || box.br().y >= crop.rows) {
        return std::nullopt;
    }

    box.x += window.x;
    box.y += window.y;
    constexpr int edgePadding = 3;
    box.x = std::max(0, box.x - edgePadding);
    box.y = std::max(0, box.y - edgePadding);
    box.width = std::min(bgr.cols - box.x, box.width + 2 * edgePadding);
    box.height = std::min(bgr.rows - box.y, box.height + 2 * edgePadding);
    if (!box.contains(click)) {
        return std::nullopt;
    }

    const double compactness = std::clamp(
        static_cast<double>(area) / static_cast<double>(box.area()), 0.0, 1.0);
    if (compactness < 0.25) {
        return std::nullopt;
    }
    const double sizeScore = std::clamp(
        1.0 - static_cast<double>(area) / static_cast<double>(cropArea * 0.35), 0.0, 1.0);
    const double separationScore = std::clamp((colourSeparation - 11.0) / 40.0, 0.0, 1.0);
    return Candidate{box,
                     0.40 + 0.30 * separationScore + 0.20 * compactness + 0.10 * sizeScore};
}

} // namespace

std::optional<SelectionResult> SeededObjectSelector::select(
    const cv::Mat& bgrFrame,
    const FramePoint& click) const
{
    if (bgrFrame.empty() || bgrFrame.type() != CV_8UC3) {
        return std::nullopt;
    }

    const cv::Point seed{
        static_cast<int>(std::lround(click.x)),
        static_cast<int>(std::lround(click.y))};
    if (seed.x < 0 || seed.y < 0 || seed.x >= bgrFrame.cols || seed.y >= bgrFrame.rows) {
        return std::nullopt;
    }

    std::optional<Candidate> best;
    for (const int radius : std::array{24, 48, 96, 160}) {
        const auto candidate = candidateAtScale(bgrFrame, seed, radius);
        if (candidate && (!best || candidate->confidence > best->confidence)) {
            best = candidate;
        }
    }

    if (!best) {
        return std::nullopt;
    }

    return SelectionResult{
        {static_cast<double>(best->box.x),
         static_cast<double>(best->box.y),
         static_cast<double>(best->box.width),
         static_cast<double>(best->box.height)},
        best->confidence};
}

{
    {
        std::lock_guard lock(commandMutex_);
        stopping_ = true;
        command_.reset();
        pendingSelection_.reset();
    }
    commandReady_.notify_one();
    if (worker_.joinable()) {
        worker_.join();
    }
}

void TrackingController::offerFrame(GstBuffer* buffer, const GstVideoInfo& info) noexcept
{
    TrackingFramePtr frame;
    try {
        frame = TrackingFrame::capture(buffer, info);
    } catch (...) {
        return;
    }
    if (!frame) {
        return;
    }

    {
        std::lock_guard lock(latestFrameMutex_);
        latestFrame_ = frame;
    }

    const auto admission = lifecycle_.admitUpdate([this] {
        skippedFrames_.fetch_add(1, std::memory_order_relaxed);
    });
    if (!admission) {
        return;
    }

    {
        std::lock_guard lock(commandMutex_);
        command_ = Command{CommandKind::Update, admission->generation, std::move(frame), {}};
    }
    commandReady_.notify_one();
}

void TrackingController::selectTarget(FramePoint point)
{
    const quint64 generation = lifecycle_.beginSelection();
    setState(TrackingState::Detecting);
    clearBox();

    TrackingFramePtr frame;
    {
        std::lock_guard lock(latestFrameMutex_);
        frame = latestFrame_;
    }
    if (!frame) {
        setState(TrackingState::Ready);
        return;
    }

    Command selection{CommandKind::Select, generation, std::move(frame), point};
    if (lifecycle_.tryBeginCommand()) {
        {
            std::lock_guard lock(commandMutex_);
            command_ = std::move(selection);
        }
        commandReady_.notify_one();
    } else {
        std::lock_guard lock(commandMutex_);
        pendingSelection_ = std::move(selection);
    }
}

void TrackingController::reset()
{
    bool stateDidChange = false;
    lifecycle_.reset([this, &stateDidChange] {
        completedUpdates_.store(0, std::memory_order_relaxed);
        skippedFrames_.store(0, std::memory_order_relaxed);
        lastUpdateMilliseconds_.store(0.0, std::memory_order_relaxed);
        lastResultAgeMilliseconds_.store(0.0, std::memory_order_relaxed);
        stateDidChange = state_.exchange(TrackingState::Ready) != TrackingState::Ready;
    });
    {
        std::lock_guard lock(commandMutex_);
        pendingSelection_.reset();
    }
    {
        std::lock_guard lock(latestFrameMutex_);
        latestFrame_.reset();
    }
    if (stateDidChange) {
        emit stateChanged(TrackingState::Ready);
    }
    clearBox();
}

void TrackingController::workerLoop()
{
    for (;;) {
        Command command;
        {
            std::unique_lock lock(commandMutex_);
            commandReady_.wait(lock, [this] { return stopping_ || command_.has_value(); });
            if (stopping_) {
                return;
            }
            command = std::move(*command_);
            command_.reset();
        }

        Result result = execute(command);
        QMetaObject::invokeMethod(
            this,
            [this, result = std::move(result)]() mutable { handleResult(std::move(result)); },
            Qt::QueuedConnection);
    }
}

TrackingController::Result TrackingController::execute(const Command& command)
{
    try {
        const auto mapped = command.frame->mapBgr();
        if (!mapped) {
            return {ResultKind::Error, command.generation, std::nullopt,
                    QStringLiteral("Could not map the tracking frame.")};
        }

        if (command.kind == CommandKind::Select) {
            engine_->reset();
            const auto selection = engine_->select(mapped->mat, command.point);
            if (!selection) {
                return {ResultKind::SelectionFailed, command.generation};
            }
            if (!engine_->initialize(mapped->mat, selection->box)) {
                return {ResultKind::SelectionFailed, command.generation};
            }
            return {ResultKind::Tracking, command.generation, selection->box};
        }

        const auto updateStarted = std::chrono::steady_clock::now();
        const auto box = engine_->update(mapped->mat);
        const auto updateFinished = std::chrono::steady_clock::now();
        const double updateMilliseconds =
            std::chrono::duration<double, std::milli>(updateFinished - updateStarted).count();
        const double resultAgeMilliseconds =
            std::chrono::duration<double, std::milli>(updateFinished - command.frame->capturedAt()).count();
        return box ? Result{ResultKind::Updated, command.generation, box, {},
                         updateMilliseconds, resultAgeMilliseconds}
                   : Result{ResultKind::Lost, command.generation, std::nullopt, {},
                         updateMilliseconds, resultAgeMilliseconds};
    } catch (const cv::Exception& error) {
        return {ResultKind::Error, command.generation, std::nullopt,
                QString::fromUtf8(error.what())};
    } catch (const std::exception& error) {
        return {ResultKind::Error, command.generation, std::nullopt,
                QString::fromUtf8(error.what())};
    } catch (...) {
        return {ResultKind::Error, command.generation, std::nullopt,
                QStringLiteral("Unknown tracking error.")};
    }
}

void TrackingController::handleResult(Result result)
{
    const bool trackingAfterCompletion =
        result.kind == ResultKind::Tracking || result.kind == ResultKind::Updated;
    if (!lifecycle_.completeCommand(
            result.generation, trackingAfterCompletion, [this, &result] {
            if (result.kind == ResultKind::Updated || result.kind == ResultKind::Lost) {
                lastUpdateMilliseconds_.store(result.updateMilliseconds, std::memory_order_relaxed);
                lastResultAgeMilliseconds_.store(result.resultAgeMilliseconds,
                    std::memory_order_relaxed);
                if (result.kind == ResultKind::Updated) {
                    completedUpdates_.fetch_add(1, std::memory_order_relaxed);
                }
            }
        })) {
        schedulePendingSelection();
        return;
    }

    switch (result.kind) {
    case ResultKind::Tracking:
    case ResultKind::Updated:
        {
            std::lock_guard lock(boxMutex_);
            box_ = result.box;
        }
        if (result.kind == ResultKind::Tracking) {
            emit selectionCandidate(*result.box);
        }
        emit targetBoxChanged(*result.box);
        setState(TrackingState::Tracking);
        break;
    case ResultKind::Lost:
        clearBox();
        setState(TrackingState::Lost);
        break;
    case ResultKind::SelectionFailed:
        clearBox();
        setState(TrackingState::Ready);
        break;
    case ResultKind::Error:
        clearBox();
        setState(TrackingState::Error);
        emit errorOccurred(result.error);
        break;
    }
    emit statsChanged(stats());
    schedulePendingSelection();
}

void TrackingController::schedulePendingSelection()
{
    std::optional<Command> selection;
    {
        std::lock_guard lock(commandMutex_);
        if (pendingSelection_) {
            selection = std::move(pendingSelection_);
            pendingSelection_.reset();
        }
    }
    if (!selection || !lifecycle_.tryBeginCommand()) {
        if (selection) {
            std::lock_guard lock(commandMutex_);
            pendingSelection_ = std::move(selection);
        }
        return;
    }
    {
        std::lock_guard lock(commandMutex_);
        command_ = std::move(selection);
    }
    commandReady_.notify_one();
}

void TrackingController::setState(TrackingState next)
{
    if (state_.exchange(next) != next) {
        emit stateChanged(next);
    }
}

void TrackingController::clearBox()
{
    bool hadBox = false;
    {
        std::lock_guard lock(boxMutex_);
        hadBox = box_.has_value();
        box_.reset();
    }
    if (hadBox) {
        emit targetCleared();
    }
}

        return ++generation_;
    }

    template <typename OnSkipped>
    [[nodiscard]] std::optional<UpdateAdmission> admitUpdate(OnSkipped&& onSkipped)
    {
        std::lock_guard lock(mutex_);
        if (!tracking_) {
            return std::nullopt;
        }
        if (commandActive_) {
            std::forward<OnSkipped>(onSkipped)();
            return std::nullopt;
        }
        commandActive_ = true;
        return UpdateAdmission{generation_};
    }

    [[nodiscard]] bool tryBeginCommand()
    {
        std::lock_guard lock(mutex_);
        if (commandActive_) {
            return false;
        }
        commandActive_ = true;
        return true;
    }

    template <typename OnCurrent>
    [[nodiscard]] bool completeCommand(
        quint64 generation,
        bool trackingAfterCompletion,
        OnCurrent&& onCurrent)
    {
        std::lock_guard lock(mutex_);
        commandActive_ = false;
        if (generation != generation_) {
            return false;
        }
        std::forward<OnCurrent>(onCurrent)();
        tracking_ = trackingAfterCompletion;
        return true;
    }

    template <typename OnReset>
    void reset(OnReset&& onReset)
    {
        std::lock_guard lock(mutex_);
        ++generation_;
        tracking_ = false;
        std::forward<OnReset>(onReset)();
    }

    [[nodiscard]] bool isCurrent(quint64 generation) const
    {
        std::lock_guard lock(mutex_);
        return generation == generation_;
    }

private:
    mutable std::mutex mutex_;
    quint64 generation_{0};
    bool tracking_{false};
    bool commandActive_{false};
};

inline double intersectionOverUnion(const FrameRect& lhs, const FrameRect& rhs) noexcept
{
    const double left = std::max(lhs.x, rhs.x);
    const double top = std::max(lhs.y, rhs.y);
    const double right = std::min(lhs.x + lhs.width, rhs.x + rhs.width);
    const double bottom = std::min(lhs.y + lhs.height, rhs.y + rhs.height);
    const double intersection = std::max(0.0, right - left) * std::max(0.0, bottom - top);
    const double unionArea = lhs.width * lhs.height + rhs.width * rhs.height - intersection;
    return unionArea > 0.0 ? intersection / unionArea : 0.0;
}

void MainWindow::updateRuntimeTelemetry()

    AbstractPipeline* pipeline = nullptr;
    if (sourceMode_ == SourceMode::File) {
        pipeline = &filePipeline_;
    } else if (sourceMode_ == SourceMode::Camera) {
        pipeline = &cameraPipeline_;
    }
    if (pipeline == nullptr) {
        return;
    }

    const TrackingStats stats = tracker_.stats();
    const bool trackingActive = tracker_.state() == TrackingState::Tracking;
    const RuntimeRates rates = telemetrySampler_.sample(
        {pipeline->observedFrameCount(),
            displayedFrames_,
            stats.completedUpdates,
            stats.skippedFrames,
            stats.lastUpdateMilliseconds,
            stats.lastResultAgeMilliseconds,
            trackingActive},
        monotonicTimer_.elapsed());
    runtimeTelemetry_->setText(formatRuntimeTelemetry(rates));
}

namespace {
struct DisplayGeometry
{
    double scale{};
    double offsetX{};
    double offsetY{};
    double width{};
    double height{};
};

std::optional<DisplayGeometry> displayGeometry(QSizeF widgetSize, QSize frameSize)
{
    if (widgetSize.width() <= 0.0 || widgetSize.height() <= 0.0
        || frameSize.width() <= 0 || frameSize.height() <= 0) {
        return std::nullopt;
    }

    const double scale = std::min(
        widgetSize.width() / frameSize.width(),
        widgetSize.height() / frameSize.height());
    const double width = frameSize.width() * scale;
    const double height = frameSize.height() * scale;

    return DisplayGeometry{
        scale,
        (widgetSize.width() - width) / 2.0,
        (widgetSize.height() - height) / 2.0,
        width,
        height,
    };
}
} // namespace

QRectF videoDisplayRect(QSizeF widgetSize, QSize frameSize)
{
    const auto display = displayGeometry(widgetSize, frameSize);
    if (!display) {
        return {};
    }
    return {display->offsetX, display->offsetY, display->width, display->height};
}

std::optional<FramePoint> mapWidgetPointToFrame(
    QPointF click,
    QSizeF widgetSize,
    QSize frameSize)
{
    const auto display = displayGeometry(widgetSize, frameSize);
    if (!display) {
        return std::nullopt;
    }

    const double localX = click.x() - display->offsetX;
    const double localY = click.y() - display->offsetY;
    if (localX < 0.0 || localY < 0.0
        || localX > display->width || localY > display->height) {
        return std::nullopt;
    }

    return FramePoint{
        std::clamp(localX / display->scale, 0.0, static_cast<double>(frameSize.width())),
        std::clamp(localY / display->scale, 0.0, static_cast<double>(frameSize.height())),
    };
}

QRectF mapFrameRectToWidget(
    FrameRect frameRect,
    QSizeF widgetSize,
    QSize frameSize)
{
    const auto display = displayGeometry(widgetSize, frameSize);
    if (!display) {
        return {};
    }

    return {
        display->offsetX + frameRect.x * display->scale,
        display->offsetY + frameRect.y * display->scale,
        frameRect.width * display->scale,
        frameRect.height * display->scale,
    };
}

void TrackingControllerTests::completionClosesTrackingBeforeAdmittingNextOffer()
{
    QFETCH(QString, resultKind);
    TrackingLifecycle lifecycle;
    const quint64 generation = lifecycle.beginSelection();
    QVERIFY(lifecycle.tryBeginCommand());
    QVERIFY(lifecycle.completeCommand(generation, true, [] {}));
    QVERIFY(lifecycle.admitUpdate([] {}));

    std::mutex gateMutex;
    std::condition_variable gateChanged;
    bool publicationEntered = false;
    bool releaseCompletion = false;
    bool completionWasCurrent = false;
    std::thread completion([&] {
        completionWasCurrent = lifecycle.completeCommand(generation, false, [&] {
            std::unique_lock lock(gateMutex);
            publicationEntered = true;
            gateChanged.notify_one();
            gateChanged.wait(lock, [&] { return releaseCompletion; });
        });
    });

    {
        std::unique_lock lock(gateMutex);
        gateChanged.wait(lock, [&] { return publicationEntered; });
    }

    std::optional<TrackingLifecycle::UpdateAdmission> racingAdmission;
    std::atomic_bool offerStarted{false};
    std::thread offer([&] {
        offerStarted = true;
        racingAdmission = lifecycle.admitUpdate([] {});
    });
    QTRY_VERIFY(offerStarted.load());

    {
        std::lock_guard lock(gateMutex);
        releaseCompletion = true;
    }
    gateChanged.notify_one();
    completion.join();
    offer.join();

    QVERIFY2(completionWasCurrent, qPrintable(resultKind));
    QVERIFY2(!racingAdmission, qPrintable(resultKind));
}

void TrackingControllerTests::updateAdmissionIsAtomicWithReset()
{
    TrackingLifecycle lifecycle;
    const quint64 trackingGeneration = lifecycle.beginSelection();
    QVERIFY(lifecycle.tryBeginCommand());
    QVERIFY(lifecycle.completeCommand(trackingGeneration, true, [] {}));

    std::barrier start{3};
    std::optional<TrackingLifecycle::UpdateAdmission> admission;
    std::thread offer([&] {
        start.arrive_and_wait();
        admission = lifecycle.admitUpdate([] {});
    });
    std::thread reset([&] {
        start.arrive_and_wait();
        lifecycle.reset([] {});
    });
    start.arrive_and_wait();
    offer.join();
    reset.join();

    if (admission) {
        QVERIFY(!lifecycle.isCurrent(admission->generation));
    }
    QVERIFY(!lifecycle.admitUpdate([] {}));
}
