# Triple Redundant FADEC Simulator and SCADA

A browser-based educational engine-control simulation co-developed by Demir Akın and Emre Karausta using AI-assisted code generation and integration. It demonstrates a simplified plant, PI fuel control, three-channel voting, fault responses and SCADA-style instrumentation. The existing MIT licence and in-app contributor credits are retained.

## Run

Open `index.html` in a modern desktop browser. No installation, server, account or build is required. Select **EN** or **TR** for the interface language. The application uses a fixed 50 ms simulation step (20 Hz); browser scheduling can run slower under load.

## Demonstration

1. Click **START ENGINE** and watch CRANK, LIGHT-OFF, ACCEL and RUN. Move the thrust lever to observe the spool and temperature response.
2. Select **Half-blind**: channel C's exhaust-temperature fault reduces availability to two channels. **Leader handover** isolates A and transfers authority to B.
3. Select **Common-mode**: all three N2 channels agree on the biased reading, while the onboard model detects the inconsistency. Contrast with **Total loss** (model synthesis) and **Open-loop** (measurement loss together with model failure).
4. Try **Force: Overspeed** to latch protection and reduce commanded fuel. Clear faults to recover. Arm **Start: Hot** or **Start: Hung** before starting to demonstrate aborted starts.
5. Enable **IETM**, select an indicator and expand its live explanation. **AUTO · FAB** exposes the simulated mission and decision log.

Reload the page to repeat from the identical initial state and seeded noise sequence. Clear-faults resets injected/latching faults, not the entire plant or random-number sequence.

## Tests

Node.js 20 or newer is needed only for tests:

```sh
npm install
npx playwright install chromium
npm test
```

On macOS the suite also discovers an installed Google Chrome. Alternatively set `PLAYWRIGHT_CHROMIUM_EXECUTABLE` to a Chromium/Chrome executable. Set `EVIDENCE_DIR=evidence` to regenerate screenshots and scenario measurements.

The tests drive the real HTML application in Chromium, including the model and UI controls. Most advance deterministic steps directly, so a simulated startup does not require a real-time wait. See [verification](VERIFICATION.md) and [scenario measurements](evidence/scenarios.json).

## Scope

This is a synthetic educational simulation, not production engine software, hardware-in-the-loop validation, aircraft certification evidence or a model calibrated against a particular engine. Fault scenarios demonstrate this implementation's behavior under stated assumptions. The CV's co-developed browser-simulation claim is supported; real ECU communication and thermocouple firmware exercises are separate work and are not supplied here.

The release copy corrects displayed 50 Hz labels to the application's actual 20 Hz update rate; it does not change plant/control parameters. A static footer that incorrectly asserted normal health during faults is relabelled as an educational simulation. Before publication, confirm that both contributors approve distributing the co-developed material and that internship-related material is cleared.

# Verification record

Verified 22 October 2026 on macOS arm64 using Node.js, Playwright 1.62.1 and installed Google Chrome in an isolated headless session. No real engine, aircraft, motor or controller was connected.

## Result

**19/19 browser tests passed.** Reproduce with `npm test` after the test dependencies in README are installed. Evidence regeneration: `EVIDENCE_DIR=evidence npm test`.

- Startup reaches RUN and approximately 60% N2 at idle; a 75% lever command raises N2, and shutdown spins down. The actual start button and thrust slider are used.
- All ten scenario buttons exercise their real handlers: nominal, half-blind, dual isolation, leader handover, total loss, open-loop, single-channel, common-mode, onboard-model crash and CCDL loss. Assertions check the expected availability, isolation, leader, synthesis, model residual or link state, plus fault-log latching and recovery.
- Hot and hung starts abort with zero commanded fuel; clearing faults permits a new start.
- Overspeed latches and commanded fuel is reduced to no more than 120 model units until reset. The forced-overspeed injection intentionally keeps plant speed high; this test proves simulated protection output, not real deceleration.
- Every 16-bit fault word round trips through the real encoder/decoder (65,536 values).
- Repeating an identical input sequence on a fresh page produces an identical model state.
- English/Turkish controls and expanded technical-help close behavior work.
- The ordinary browser timer advances the model through the briefing start button.
- No uncaught page errors during the tests.

## Reproduced defects and minimal corrections

The first browser suite passed 16 of 18 checks. The two failures established that the displayed frequency (50 Hz) contradicted the running timer (50 ms / 20 Hz). The labels and live-help explanation were corrected in the copy, preserving the plant and control parameters. A separate failing regression established that the static footer said SYSTEM NOMINAL during a channel-isolation fault; it now identifies the application as an educational simulation. The final expanded suite passed all 19 tests.

## Master CV correspondence

The supplied application supports the co-developed, AI-assisted browser FADEC/SCADA simulation claim: simulated engine response, redundancy states and fault responses are operational in the copied application. The retained credits distinguish the contributors. The separate embedded ECU-header and MAX31855 exercises in the CV are not included and are not claimed to be verified by these browser tests.

## Limits

The tests cover this synthetic model and interface. They do not calibrate it to an engine, validate aerothermal fidelity, certify fault coverage, prove bumpless transfer at every operating point or substantiate real hardware safety. Screenshots were visually inspected. Contributors and internship owners must clear the co-developed content before publication; the existing MIT file has been preserved without inventing broader permissions.

  decode(fw){ return {alan:(fw>>13)&7,kod:(fw>>9)&15,ch:(fw>>7)&3,voter:(fw>>5)&3,comp:fw&31}; },
  hex(fw){ return '0x'+fw.toString(16).toUpperCase().padStart(4,'0'); },
  kodName(alan,kod){
    if(alan===3) return this.KKOD[kod]||('KOD '+kod);
    if(alan===0) return this.SKOD[kod]||('KOD '+kod);
    if(alan===2) return this.LKOD[kod]||('KOD '+kod);
    return 'KOD '+kod;
  }
};

      let devN=0;
      if(av.length>=3){const med=median3(lane.A[p.id],lane.B[p.id],lane.C[p.id]);
        fadec.voted[p.id]=med;
        for(const ch of av) if(Math.abs(lane[ch][p.id]-med)>p.eps){ iso[ch]=1; devN++; }
      } else if(av.length===2) fadec.voted[p.id]=(lane[av[0]][p.id]+lane[av[1]][p.id])/2;
      else if(av.length===1) fadec.voted[p.id]=lane[av[0]][p.id];
      else fadec.voted[p.id]=fadec.voted[p.id]??plant[p.id];
      const lostN=3-av.length;                                  // parametre-başına voter durumu
      fadec.voterP[p.id] = av.length<=1?3 : (lostN>=2||devN>=2)?2 : (devN===1||lostN===1)?1 : 0;
    }
    for(const ch of ORDER)
      fadec.health[ch]=!(inj[`CPU:${ch}`]||iso[ch]||CRIT.some(p=>loss[ch][p.id]));
    fadec.iso={A:!!iso.A,B:!!iso.B,C:!!iso.C};
    fadec.laneN2={A:lane.A.N2,B:lane.B.N2,C:lane.C.N2};
    fadec.laneEGT={A:lane.A.EGT,B:lane.B.EGT,C:lane.C.EGT};
    fadec.laneN1={A:lane.A.N1,B:lane.B.N1,C:lane.C.N1};
    fadec.degrade=ORDER.filter(ch=>fadec.health[ch]).length;
    fadec.N2voted=plant.N2voted=fadec.voted.N2;
    const rawMaxN2=Math.max(lane.A.N2??0,lane.B.N2??0,lane.C.N2??0);
    if(rawMaxN2>OVSP_TRIP) fadec.overspeed=true;   // LATCH: bir kez tripleyince reset'e kadar tutar (havacılık)
  }
  function stepOBM(Wf,dt){
    if(OBM.crashed){OBM.n2Out=OBM.egtOut=OBM.n2Synth=OBM.egtSynth=false;return;}
    OBM.n2+=(n2_ss(Wf)-OBM.n2)*(dt/TAU_N2);
    let egt_ss=EGT_IDLE+(EGT_TO-EGT_IDLE)*(OBM.n2-N2_IDLE)/(N2_TO-N2_IDLE)+(env.ait-15);
    const demand=Math.max(15,egt_ss)+KLEAD*(Wf-Wf_eq(OBM.n2));
    OBM.egtFast+=(demand-OBM.egtFast)*(dt/TAU_EGT_FAST);
    OBM.egtSlow+=(demand-OBM.egtSlow)*(dt/TAU_EGT_SLOW);
    OBM.EGT=EGT_FAST_FRAC*OBM.egtFast+(1-EGT_FAST_FRAC)*OBM.egtSlow;
    OBM.n2Exp=OBM.n2;OBM.egtExp=OBM.EGT;
    OBM.n2Resid=fadec.voted.N2!=null?Math.abs(fadec.voted.N2-OBM.n2Exp):0;
    OBM.egtResid=fadec.voted.EGT!=null?Math.abs(fadec.voted.EGT-OBM.egtExp):0;
    OBM.n2Out=OBM.n2Resid>OBM_N2_BAND;OBM.egtOut=OBM.egtResid>OBM_EGT_BAND;
  }
  function analyticDecisions(){
    fadec.commonMode=(fadec.degrade===3&&OBM.n2Out&&!OBM.crashed);
    OBM.n2Synth=(fadec.degrade<=1&&!OBM.crashed);
    if(OBM.n2Synth){fadec.voted.N2=OBM.n2Exp;fadec.N2voted=plant.N2voted=fadec.voted.N2;}
    OBM.egtSynth=(fadec.degrade<=1&&!OBM.crashed);      // EGT de Wf+N2'den sentezlenir (analitik redundans)
    if(OBM.egtSynth){fadec.voted.EGT=OBM.egtExp;}
    fadec.openLoop=(fadec.degrade===0&&OBM.crashed);
    fadec.reducedMode = (fadec.degrade<=1||OBM.n2Synth) ? 2 : (fadec.degrade===2||fadec.commonMode) ? 1 : 0; // indirgenmiş mod seviyesi
  }
  function runAllLanes(dt){
    const wf={}, cpuOk=ch=>!inj[`CPU:${ch}`];
    // kontrol SENSÖR sağlığıyla DEĞİL, CPU canlılığıyla kapılı:
    // sensörleri gitse bile CPU'su çalışan lane, OBM-sentez N2 üzerinden yakıt komutlar (model-tabanlı reversiyoner kontrol)
    for(const ch of ORDER) wf[ch]=cpuOk(ch)?controlLaw(fadec.N2_tgt,ctrl[ch],dt):null;
    const Wf_actual=plant.WfCmd_applied;
    for(const ch of ORDER){if(wf[ch]===null||ch===arb.leader)continue;
      const err=fadec.N2_tgt-(fadec.voted.N2??0);
      ctrl[ch].i=clamp(Wf_actual-Wf_eq(fadec.N2_tgt)-KP*err,-WF_MAX,WF_MAX);}
    return wf;
  }
  function arbitrate(wfLane,dt){
    const cpuOk=ch=>!inj[`CPU:${ch}`];
    // lider: önce tam-sağlıklı; yoksa CPU'su canlı herhangi bir lane (sentez ile sürer)
    const want=ORDER.filter(ch=>fadec.health[ch])[0] ?? ORDER.filter(cpuOk)[0] ?? arb.leader;
    if(!fadec.health[arb.leader])arb.switchT+=dt;else arb.switchT=0;
    if(arb.leader!==want&&(arb.switchT>=SWITCH_HOLD||!ORDER.includes(arb.leader))){
      arb.interlock=false;arb.prev=arb.leader;arb.leader=want;arb.switchT=0;arb.lastSwitch=fadec.cycle;
    } else if(fadec.cycle-arb.lastSwitch>2){arb.interlock=true;}
    fadec.leader=arb.leader;
    // lider yoksa (hiç CPU canlı değil): açık-çevrimde programlı rölanti, değilse flameout tabanı
    return wfLane[arb.leader] ?? (fadec.openLoop ? Wf_eq(fadec.N2_tgt) : WF_MIN);
  }
  // ---- FAB (Ana Uçuş Bilgisayarı) — FADEC DIŞI. Sağlık OKUR, hedef N2 ÜRETİR ----
  const LEGS=[
    {id:'TAXI',P:0,n2:60,hold:4,alt:0},
    {id:'TAKEOFF',P:1,n2:100,hold:6,alt:0},
    {id:'CLIMB',P:3,n2:96,hold:12,alt:8000},
    {id:'CRUISE',P:4,n2:88,hold:15,alt:11000},
    {id:'LOITER',P:4,n2:80,hold:20,alt:9000},
    {id:'DASH',P:1,n2:100,hold:8,alt:11000},   // tam itki — derate burayı kısar
    {id:'RTB',P:4,n2:88,hold:15,alt:10000},
    {id:'APPROACH',P:6,n2:70,hold:10,alt:1500},
    {id:'LANDING',P:0,n2:60,hold:6,alt:0},
    {id:'SHUTDOWN',P:0,n2:0,end:true,alt:0},
  ];
  const RTB_IX=LEGS.findIndex(l=>l.id==='RTB');
  const fab={engaged:false,leg:0,legT:0,derate:false,rtb:false,emergency:false,log:[]};
  function fabLog(reason){ fab.log.push({cyc:fadec.cycle,leg:LEGS[fab.leg].id,reason}); if(fab.log.length>80)fab.log.shift(); }
  function supervise(){                                   // sağlık → kısıt (ACİL>RTB>DERATE>SCRIPT)
    const out={derateCeiling:null,idleSafe:false};
    if(fadec.overspeed||fadec.openLoop){
      if(!fab.emergency){fab.emergency=true;fabLog(LANG==='tr'?'overspeed/open-loop → ACİL idle/safe':'overspeed/open-loop → EMERGENCY idle/safe');}
      out.idleSafe=true; return out;
    }
    if(fab.emergency){fab.emergency=false;fabLog(LANG==='tr'?'acil temizlendi → misyona dön':'emergency cleared → resume mission');}
    if(fadec.degrade<=1 && !fab.rtb){fab.rtb=true;fabLog(LANG==='tr'?'degrade=1-kanal → RTB latch':'degrade=1-channel → RTB latch');}
    if(fadec.degrade===2){
      if(!fab.derate){fab.derate=true;fabLog('degrade=2oo3 → DASH inhibit (derate 88%)');}
      out.derateCeiling=88;
    } else if(fab.derate && fadec.degrade===3){fab.derate=false;fabLog(LANG==='tr'?'degrade=3oo3 → derate kalktı':'degrade=3oo3 → derate lifted');}
    return out;
  }
  function stepFAB(dt){
    if(!fab.engaged) return null;                         // MANUEL → kol kullanıcıda
    const sup=supervise();                                // sağlık HER ZAMAN script'ten önce
    if(fab.rtb && fab.leg<RTB_IX){fab.leg=RTB_IX;fab.legT=0;fabLog(LANG==='tr'?'SÜPERVİZÖR: RTB bacağına atlandı':'SUPERVISOR: jumped to RTB leg');}
    const leg=LEGS[fab.leg];
    if(!leg.end){ fab.legT+=dt;
      if(fab.legT>=leg.hold){ fab.leg=Math.min(fab.leg+1,LEGS.length-1); fab.legT=0;
        fabLog('script: '+leg.id+' → '+LEGS[fab.leg].id); } }
    setEnv(LEGS[fab.leg].alt);                            // irtifa → θ/δ
    let N2_tgt=LEGS[fab.leg].n2;
    if(sup.derateCeiling!=null) N2_tgt=Math.min(N2_tgt,sup.derateCeiling);  // derate AŞAĞI çeker
    if(sup.idleSafe) N2_tgt=60;                           // acil her şeyi ezer
    return {leg:LEGS[fab.leg].id,P:LEGS[fab.leg].P,N2_tgt};
  }
  function fabEngage(){ fab.engaged=true; fab.leg=0; fab.legT=0; fab.derate=fab.rtb=fab.emergency=false;
    fab.log.length=0; fabLog(LANG==='tr'?'FAB devrede — misyon başladı (TAXI)':'FAB engaged — mission started (TAXI)'); }
  function fabDisengage(){ if(fab.engaged){ fab.engaged=false; fabLog(LANG==='tr'?'FAB devre dışı — kontrol pilota':'FAB disengaged — control to pilot'); } }

  // ---- START SEKANSI (gerçek FSM: light-off / starter cutout / hung / hot start) ----
  const ST_LIGHT=18, ST_CUTOUT=50, ST_IDLE=58, ST_EGT_LIM=720, STARTER_N2=24, ST_WF=620;
  const START={phase:'OFF',t:0,stallT:0,lastN2:0};
  function startReset(){ START.phase='OFF';START.t=0;START.stallT=0;START.lastN2=0;plant.starter=0;plant.startMode=false; }
  function stepStart(dt){
    const p=plant;
    switch(START.phase){
      case 'OFF':       START.phase='CRANK'; START.t=0; p.startMode=true; return {wf:0,done:false};
      case 'CRANK':     p.starter=1; START.t+=dt;                          // kuru çevirme, yakıt yok
                        if(p.N2>=ST_LIGHT){START.phase='LIGHTOFF';START.t=0;}
                        return {wf:0,done:false};
      case 'LIGHTOFF':  p.starter=1; START.t+=dt;                          // ateşleme + start yakıtı
                        { const wf = ST_WF;
                          if(p.EGT>ST_EGT_LIM){START.phase='HOT';return {wf:0,done:false};}  // hot start
                          if(START.t>0.8) START.phase='ACCEL';
                          return {wf,done:false}; }
      case 'ACCEL':     { p.starter = p.N2<ST_CUTOUT?1:0;                  // starter cutout @50%
                          if(p.EGT>ST_EGT_LIM){START.phase='HOT';return {wf:0,done:false};}
                          const wf = inj._hung ? ST_WF*0.55 : WF_IDLE;   // _hot artık N2'yi hızlandırmaz (EGT cezası ayrı)
                          const rate=(p.N2-START.lastN2)/dt; START.lastN2=p.N2;
                          if(p.N2<ST_IDLE && rate<1.0){ START.stallT+=dt;       // hung: idle altında tırmanamıyor
                            if(START.stallT>2.0){START.phase='HUNG';return {wf:0,done:false};} } else START.stallT=0;
                          if(p.N2>=ST_IDLE){START.phase='RUN';p.startMode=false;}
                          return {wf,done:false}; }
      case 'RUN':       p.starter=0; return {done:true};                  // start tamam → normal kontrol
      case 'HUNG': case 'HOT': p.starter=0; return {wf:0,done:false,abort:START.phase};
    }
  }

  const rng=makeRng(1337);
  return {C:{N2_IDLE,N2_MAX,N2_TO,EGT_REDLINE,OVSP_TRIP,Wf_eq,ORDER},
    plant,fadec,OBM,arb,inj,env,setEnv,fab,LEGS,RTB_IX,stepFAB,fabEngage,fabDisengage,
    START,stepStart,startReset,
    stepPlant,controlLaw,voteHealth,stepOBM,analyticDecisions,runAllLanes,arbitrate,rng};
})();

  s.cycle=f.cycle;

  const SPH={OFF:0,CRANK:1,LIGHTOFF:2,ACCEL:3,RUN:4,HUNG:6,HOT:6}; // GM#2: abort → anormal S6 (.abn), SHUTDOWN değil

  s.n2=f.voted.N2??0; s.egt=f.voted.EGT??15; s.n1=f.voted.N1??p.N1; s.wf=p.Wf;

  const isoN=C.ORDER.filter(k=>!f.health[k]).length;
  for(const k of C.ORDER){const c=s.ch[k];
    c.iso=!f.health[k]; c.leader=(k===a.leader); c.healthy=f.health[k];
    c.n2=(f.laneN2[k]!=null)?f.laneN2[k]:s.n2;
    c.egt=(f.laneEGT[k]!=null)?f.laneEGT[k]:s.egt;}
  s.leader=a.leader;
  const devIso=C.ORDER.filter(k=>f.iso[k]).length;          // ε-sapmayla izole edilen kanal sayısı

  s.degrade=f.degrade;

  s.ccdl=f.ccdl; s.interlock=a.interlock; s.openLoop=f.openLoop; s.overspeed=f.overspeed;
  s.sync=s.cycle>3 && s.degrade>=2 && f.ccdl.AB && f.ccdl.AC && f.ccdl.BC; // #2: CCDL kaybı sync'i düşürür
  // status words — EGEMEN bit düzeniyle (render bu konumları okur)
  let sw1=0;
  if(s.S===4)sw1|=1<<7; if(a.leader!=='—')sw1|=1<<6; if(s.pfr.length||isoN)sw1|=1<<5;
  if(s.egt>Driver.AMBER_EGT)sw1|=1<<4; if(isoN>=2)sw1|=1<<3; if(o.n2Synth)sw1|=1<<2;
  if(s.S>=1&&s.S<=3)sw1|=1<<1; if(isoN===0&&!f.overspeed)sw1|=1<<0; s.sw1=sw1;
  let sw2=0;
  if(s.sync)sw2|=1<<7; if(a.interlock)sw2|=1<<6;
  if(f.health.A)sw2|=1<<5; if(f.health.B)sw2|=1<<4; if(f.health.C)sw2|=1<<3;
  if(s.voter===0)sw2|=1<<2; if(f.degrade>=2)sw2|=1<<1;
  if(f.ccdl.AB&&f.ccdl.AC&&f.ccdl.BC)sw2|=1<<0; s.sw2=sw2;
}

/* ---- SEAM: gerçek bir tick. Ana döngü (setInterval) bunu çağırır. ---- */
function realStep(dt){
  const f=BK.fadec;
  if(!FADECState.engineOn){
    BK.fab.engaged=false; BK.startReset();               // motor kapalı → FAB + start sıfırla
    f.N2_tgt=0; BK.plant.WfCmd_applied=0; BK.stepPlant(0,dt);
  } else {
    const st=BK.stepStart(dt);                           // START FSM (CRANK→LIGHTOFF→ACCEL→RUN)
    if(!st.done){
      f.N2_tgt=0;
      BK.plant.WfCmd_applied=st.wf; BK.stepPlant(st.wf,dt); // start çizelgesi — kontrol yasası DEVRE DIŞI
    } else {
      const autoCmd=BK.stepFAB(dt);                       // RUN → normal: AUTO/MANUEL
      if(autoCmd){ f.N2_tgt=autoCmd.N2_tgt;
        FADECState.tla=Math.max(0,Math.min(100,Math.round((autoCmd.N2_tgt-BK.C.N2_IDLE)/0.40)));
      } else f.N2_tgt=BK.C.N2_IDLE+FADECState.tla*0.40;
      const wfLane=BK.runAllLanes(dt);
      let WfCmd=BK.arbitrate(wfLane,dt);
      if(f.overspeed) WfCmd=Math.min(WfCmd,120);          // bağımsız overspeed yakıt kesme
      BK.plant.WfCmd_applied=WfCmd; BK.stepPlant(WfCmd,dt);
      if(BK.inj._ovsp) BK.plant.N2=Math.max(BK.plant.N2,118); // fiziksel aşırı dönüş
    }
  }
  BK.voteHealth(BK.rng,dt);
  BK.stepOBM(BK.plant.Wf,dt);
  BK.analyticDecisions();
  writeFADECState();
  telemetryToPFR();
  renderFAB();
  renderRedundancy();
}

/* ---- pushFault: PFR'a latch + dedup + decoder besle (entegrasyon temizliğinde yanlışlıkla silinmişti) ---- */
function pushFault(fw, warn){
  const s=FADECState;
  s.lastFW=fw;                                          // decoder en son word'ü gösterir
  if(s.pfr.some(r=>r.fw===fw)) return;                  // dedup: aynı word zaten latch'li
  const d=FW.decode(fw);
  const decoded=`${FW.ALAN[d.alan]} · ${FW.kodName(d.alan,d.kod)} · CH=${FW.CH[d.ch]} · ${FW.VOTER[d.voter]} · COMP=${d.comp}`;
  const rec={cycle:s.cycle,fw,hex:FW.hex(fw),decoded,warn:!!warn};
  s.pfr.push(rec); if(!s.faults.includes(fw)) s.faults.push(fw); renderPFR(rec);
}

const chIdx={A:0,B:1,C:2}, compOf={N2:2,EGT:4,N1:6};
function telemetryToPFR(){
  const f=BK.fadec, o=BK.OBM;
  for(const key in BK.inj){
    if(key[0]==='C'||key[0]==='_') continue;                 // CPU: / _ovsp atla
    const c=BK.inj[key].code, parts=key.split(':'), p=parts[0], ch=parts[1];
    if(c==='S06') pushFault(FW.encode(0,1,chIdx[ch],0,compOf[p]||0),false);      // SENSOR · S-SINYAL
    else if(c==='S01'||c==='S02') pushFault(FW.encode(0,2,chIdx[ch],0,compOf[p]||0),false); // SENSOR · S-ARALIK
  }
  for(const ch of BK.C.ORDER) if(!f.health[ch]){
    if(BK.inj[`CPU:${ch}`]) pushFault(FW.encode(3,9,chIdx[ch],3,0),true);   // KANAL · K09 CPU (kök-neden ayrı)
    else pushFault(FW.encode(3,2,chIdx[ch],3,2),true);                      // KANAL · K02 IZOLE
  }
  if(f.degrade<=1)            pushFault(FW.encode(3,11,3,2,0),true);             // KANAL · K11 TEK-KANAL
  if(f.commonMode)            pushFault(FW.encode(3,7,3,0,2),true);              // KANAL · K07 (golden sapma)
  if(o.crashed)               pushFault(FW.encode(4,8,3,2,0),true);             // KONTROL · K08
  if(f.overspeed)             pushFault(FW.encode(2,1,3,0,2),true);             // LIMIT · L-OVERSPEED
  if(f.voted.EGT>Driver.REDLINE_EGT) pushFault(FW.encode(2,2,3,0,4),true);      // LIMIT · L-EGT
  if(!f.ccdl.AB)              pushFault(FW.encode(3,5,3,1,0),false);            // KANAL · K05 CCDL
}
