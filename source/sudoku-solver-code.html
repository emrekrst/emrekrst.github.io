# Sudoku solver

A C++ command-line Sudoku game with a backtracking solver that chooses the empty cell with the fewest legal candidates (minimum remaining values). The supplied text puzzle is included.

## Build and run

Requires a C++17 compiler, Make and Python 3 for CLI tests.

```sh
make
./build/sudoku                 # use board.txt from this directory
./build/sudoku path/to/puzzle.txt
make test
make clean
```

Enter `s` to select an empty cell, `a` to display a solution without changing the current board, `v` to check completion, or `q` to quit. Row/column coordinates are 1–9. A puzzle file must have exactly 81 integers in 0–9; zero means empty. Invalid, missing or conflicting puzzles return a nonzero exit status.

## Provenance and preparation changes

Recovered university coursework associated with Emre Karausta. This project is an additional programming example; it is not listed in the master CV. The standalone copy retains the original board representation, CLI and MRV solver. Preparation added input validation, atomic puzzle loading, invalid-board rejection, safe EOF handling and regression tests. Original coursework files were left untouched.

No project-wide licence has been inferred or added. Confirm rights to any supplied coursework material before public release.

See [VERIFICATION.md](VERIFICATION.md) for executed checks and limits.

- move boundary checks reject invalid coordinates/values, including minimum-integer CLI input before coordinate subtraction;
- CLI exits on EOF and recovers from nonnumeric row/column/number input;
- autosolve and quit finish within a five-second subprocess timeout.

Before fixes, independent regressions failed because the original solver accepted an all-ones complete board and the loader returned normally for a missing file. CLI EOF and nonnumeric input exceeded a subprocess timeout. The test suite now exercises those paths. Limits: solution uniqueness is not checked. The solver reports the first solution. No external puzzle corpus, performance benchmark, or exhaustive proof was run. This is an educational application, not a general Sudoku library.

//board.cpp

#include "board.h"
#include <limits>
#include <stdexcept>
using namespace std;

//define functions

//load sudoku puzzle from txt file into board array
void loadBoardFromFile(const string& filename, int board[9][9]) { //defines a function with string and array input
    ifstream file(filename);
    if (!file) throw runtime_error("Could not open puzzle: " + filename);
    int loaded[9][9] = {};
    for (auto& row : loaded) {
        for (int& value : row) {
            if (!(file >> value) || value < 0 || value > 9)
                throw runtime_error("Puzzle must contain exactly 81 integers in 0..9");
        }
    }
    string extra;
    if (file >> extra) throw runtime_error("Puzzle has extra data");
    if (!isBoardValid(loaded)) throw runtime_error("Puzzle has conflicting clues");
    for (int r = 0; r < 9; ++r)
        for (int c = 0; c < 9; ++c) board[r][c] = loaded[r][c];
}

// display sudoku board in formatted CLI grid
void displayBoard(int board[9][9]) {
    cout << "\n==============================\n";
    cout << "          SUDOKU GAME         \n"; //nice title
    cout << "==============================\n";

    for (int i = 0; i < 9; ++i) {
        if (i % 3 == 0) //if remainder equals zero
            cout << "+-------+-------+-------+\n"; //prints row borders

        for (int j = 0; j < 9; ++j) {
            if (j % 3 == 0) cout << "| "; //prints column borders

            if (board[i][j] == 0)
                cout << "_ "; //show _ for empty cells
            else
                cout << board[i][j] << " "; //show the number
        }
        cout << "|\n"; //end-of-row line
    }
    cout << "+-------+-------+-------+\n\n"; //final bottom grid line
}

//check if placing a number is valid
bool isValidMove(int board[9][9], int row, int col, int num) {
    if (row < 0 || row >= 9 || col < 0 || col >= 9 || num < 1 || num > 9) return false;
    // check row
    for (int j = 0; j < 9; ++j) {
        if (board[row][j] == num) return false; //scan row for duplicates
    }

    // check column
    for (int i = 0; i < 9; ++i) {
        if (board[i][col] == num) return false; //scan column for duplicates
    }

    // check 3x3 subgrid
    int startRow = row - row % 3; //finds the top left of the 3x3 box of interest
    int startCol = col - col % 3;
    for (int i = 0; i < 3; ++i) //scans 3x3 box for duplicates
        for (int j = 0; j < 3; ++j)
            if (board[startRow + i][startCol + j] == num)
                return false;

    return true; //valid move if duplicates not found
}

//check if all cells are filled
bool isBoardFull(int board[9][9]) {
    for (int i = 0; i < 9; ++i)
        for (int j = 0; j < 9; ++j)
            if (board[i][j] == 0) //false if any of the cells are 0
                return false;
    return true;
}

//check if the entire board is valid (for final victory check)
bool isBoardValid(int board[9][9]) {
    //validate all filled cells
    for (int i = 0; i < 9; ++i) {
        for (int j = 0; j < 9; ++j) {
            int num = board[i][j]; //store current number of the cell
            if (num != 0) {
                board[i][j] = 0; //temporarily clear current cell
                if (!isValidMove(board, i, j, num)) { //test if placing that number was valid
                    board[i][j] = num; 
                    return false;
                }
                board[i][j] = num; //restore value
            }
        }
    }
    return true; 
}

//allow user to select and fill a cell
void selectCell(int board[9][9]) {
    int row, col, num; //declare variables for coordinates and number

    cout << "Enter row (1-9): ";
    if (!(cin >> row)) {
        if (!cin.eof()) { cin.clear(); cin.ignore(numeric_limits<streamsize>::max(), '\n'); }
        cout << "Invalid numeric input.\n"; return;
    }
    cout << "Enter column (1-9): ";
    if (!(cin >> col)) {
        if (!cin.eof()) { cin.clear(); cin.ignore(numeric_limits<streamsize>::max(), '\n'); }
        cout << "Invalid numeric input.\n"; return;
    }

    // Validate before subtraction, including the minimum representable integer.
    if (row < 1 || row > 9 || col < 1 || col > 9) {
        cout << "Invalid position! Try again.\n";
        return;
    }


    row -= 1;
    col -= 1;

    //disallow overwriting filled cell
    if (board[row][col] != 0) {
        cout << "Cell already filled! Choose another.\n";
        return;
    }

    //ask user number input
    cout << "Enter number (1-9): ";
    if (!(cin >> num)) {
        if (!cin.eof()) { cin.clear(); cin.ignore(numeric_limits<streamsize>::max(), '\n'); }
        cout << "Invalid numeric input.\n"; return;
    }

    //validate number range
    if (num < 1 || num > 9) {
        cout << "Invalid number! Must be between 1 and 9.\n";
        return;
    }

    //if valid, fill cell; else print warning
    if (isValidMove(board, row, col, num)) {
        board[row][col] = num;
        cout << "Move accepted.\n";
    } else {
        cout << "Invalid move (violates Sudoku rules).\n";
    }
}

//main.cpp

#include <iostream>
#include <string>
#include "board.h"

int main(int argc, char** argv) {
    int board[9][9] = {}; //define 9x9 2D array for board number representations
    std::string filename = argc > 1 ? argv[1] : "board.txt"; //string defines a sequence of characters which is the name of the file here
    try { loadBoardFromFile(filename, board); }
    catch (const std::exception& e) { std::cerr << e.what() << "\n"; return 1; } // //use filename string to get information from the txt file to the 9x9 array

    bool running = true; //to create an infinite loop
    while (running) { //loop will always run
        displayBoard(board); //shows the board with visuals
        char command; //define a one letter char of which command is selected
        std::cout << "Enter command (s = select, a = autosolve/answer, v = validate, q = quit): "; //shows this to user from the terminal
        if (!(std::cin >> command)) break; // //lets user enter a one letter input to be the next command

        switch (command) { //this is like an if-else loop that just switches to the case whatever the command was by the user
            case 's':
                selectCell(board); //allows user to select the cell and place 1-9 number to the cell
                break;
            case 'a':
                int solved[9][9]; //defines a new array for solution
                for (int i = 0; i < 9; ++i) {
                    for (int j = 0; j < 9; ++j) {
                        solved[i][j] = board[i][j]; //prints the board to the solved array
                    }
                }
                if (solveSudoku(solved)) { //uses the algorithm for this seperate array to fill in the answers
                    std::cout << "Solution:\n"; //print this message
                    displayBoard(solved); //display the solved board
                } else {
                    std::cout << "No solution exists.\n"; //to show when algorithm fails to find a solution
                }
                break;
            case 'v':
                if (isBoardFull(board)) { //checks if board is full
                    if (isBoardValid(board)) { 
                        std::cout << "Congratulations! Puzzle solved!\n"; //prints this if solved
                        running = false; //ends game loop
                    } else {
                        std::cout << "Some cells are incorrect.\n"; //prints this if answers are incorrect, the board must be full to see this
                    }
                } else {
                    std::cout << "The board is not complete yet. Keep going!\n"; //isBoardFull function gives not true
                }
                break;
            case 'q':
                running = false; //directly ends the game loop
                break;
            default: //if none of the valid command is entered
                std::cout << "Invalid command.\n";
        }
    }
    return 0;
}

//solver.cpp
//uses backtracking with MRV

#include "board.h"
#include <limits>

using namespace std;

//helper find the cell with Minimum Remaining Values (MRV)
bool findBestCell(int board[9][9], int &row, int &col) { //new function, chooses best cell
    int minOptions = numeric_limits<int>::max(); //initialize smallest option to count to the max possible integer
    bool found = false; //finds if empty cell is found

    for (int r = 0; r < 9; r++) { // loop over every cell on the board
        for (int c = 0; c < 9; c++) {
            if (board[r][c] == 0) { //if cell is empty
                int count = 0;
                for (int num = 1; num <= 9; num++) { //count how many numbers are valid for this cell
                    if (isValidMove(board, r, c, num)) count++;
                }
                if (count < minOptions) {
                    minOptions = count;
                    row = r; //if this cell has fewer valid numbers than
                    col = c; //current min, store it as new best cell
                    found = true;
                }
            }
        }
    }
    return found; //continue scanning board until its found
}

//core solver
bool solveSudoku(int board[9][9]) {
    if (!isBoardValid(board)) return false;
    int row, col;

    if (!findBestCell(board, row, col))  //if no empty cell left
        return true; //solved

    for (int num = 1; num <= 9; num++) { //try numbers 1-9 in celected cell
        if (isValidMove(board, row, col, num)) { //if number is valid
            board[row][col] = num; //temporarily place number
            if (solveSudoku(board)) //solve the rest of the board
                return true; //and if it works its done
            board[row][col] = 0; //otherwise reset to zero and try next number (backtrack)
        }
    }
    return false; //if none worked backtrack to findBestCell step
}

#include "board.h"
#include <cassert>
#include <sstream>
#include <fstream>
int main(int argc, char** argv) {
    int b[9][9] = {};
    if (argc > 1 && std::string(argv[1]) == "invalid") {
        for(auto& row:b) for(auto& v:row) v=1;
        assert(!solveSudoku(b));
    } else if(argc > 1 && std::string(argv[1]) == "load") {
        bool rejected=false;
        try { loadBoardFromFile("no-such-puzzle.txt", b); } catch(const std::exception&) {rejected=true;}
        assert(rejected);
    } else {
        loadBoardFromFile("board.txt", b);
        assert(isBoardValid(b));
        assert(solveSudoku(b));
        assert(isBoardFull(b) && isBoardValid(b));
        const int expected[9][9] = {
            {5,3,4,6,7,8,9,1,2},{6,7,2,1,9,5,3,4,8},{1,9,8,3,4,2,5,6,7},
            {8,5,9,7,6,1,4,2,3},{4,2,6,8,5,3,7,9,1},{7,1,3,9,2,4,8,5,6},
            {9,6,1,5,3,7,2,8,4},{2,8,7,4,1,9,6,3,5},{3,4,5,2,8,6,1,7,9}};
        for (int r=0;r<9;++r) for(int c=0;c<9;++c) assert(b[r][c]==expected[r][c]);
        loadBoardFromFile("board.txt", b);
        b[0][2]=1; // Locally legal clue, but inconsistent with the puzzle solution.
        assert(isBoardValid(b));
        assert(!solveSudoku(b));
        assert(b[0][2]==1 && b[0][3]==0);
        assert(!isValidMove(b,-1,0,1));
        assert(!isValidMove(b,0,9,1));
        assert(!isValidMove(b,0,0,10));
        std::cout << "Sudoku solve PASS\n";
    }
}
