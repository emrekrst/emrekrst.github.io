# Rover obstacle-sensor evaluation

Bench measurements by Emre Karausta comparing HC-SR04 ultrasonic and VL53L0X time-of-flight sensors, using a teammate-prepared Raspberry Pi Pico/MicroPython acquisition setup during University of Southampton rover coursework.

The public data is a focused extraction of 160 readings from the original measurement workbook: five trials for seven materials, five incidence angles (0–60°), and four lateral offsets (0–6 cm), for each sensor. `data/trials.csv` retains source-cell coordinates. `data/summary.csv` recomputes means and half ranges from the trials. The private report, workbook and photographs are not redistributed.

## Reproduce

```sh
python3 -m unittest discover -s tests
python3 analyze.py
```

Analysis uses Python's standard library. To regenerate the chart in MATLAB, run `plot_results`. This optional plot requires MATLAB only.

![Measured means and half ranges](results.png)

Invalid readings are the documented sentinels: 819 cm for ToF and −0.02 cm for ultrasonic. They count as failed readings and are excluded from means. Half range is `(maximum−minimum)/2` in centimetres, not a confidence interval or percentage uncertainty. At least one valid reading is required for a mean. The original report describes nominal 10 cm placement; the ToF setup was uncalibrated, so this dataset does not establish comparative absolute accuracy.

The ultrasonic sensor gave unreliable target readings at 45–60° and five invalid readings for sponge. ToF gave five invalid readings at 6 cm lateral offset. A transparent-acrylic angle failure was a separate qualitative observation in the report, not a recorded condition in this workbook. The suggested arrangement—forward ToF and ultrasonics angled ±25°, invalid-reading rejection and fallback logic—was a design proposal, not a validated fused sensing system.

See [VERIFICATION.md](VERIFICATION.md) for evidence and limitations, and [ATTRIBUTION.md](ATTRIBUTION.md) for publication rights.

The report's prose contains numbers that differ from workbook-derived values; the release uses the workbook trials for quantitative summaries.

The original report, workbook and photographs stay private and are not copied into this package. Sensor identity and sentinel interpretation were confirmed from the report. The acquisition software is credited to a teammate; it is not included or claimed as Emre's code. No sensor was connected, no new measurements were collected, and no publication or permission to publish was established. See `ATTRIBUTION.md`.

"""Recompute summaries from anonymised trials. Python standard library only."""
from pathlib import Path
import csv
from collections import defaultdict
from statistics import mean

def summarize(sensor, readings):
    sentinel = {'ToF': 819.0, 'Ultrasonic': -0.02}[sensor]
    valid = [x for x in readings if x != sentinel]
    return (len(valid), len(readings)-len(valid), mean(valid) if valid else None,
            (max(valid)-min(valid))/2 if valid else None)

def main():
    root = Path(__file__).resolve().parent
    groups = defaultdict(list)
    with (root/'data/trials.csv').open(newline='') as f:
        for row in csv.DictReader(f):
            groups[(row['sensor'],row['experiment'],row['condition'])].append(float(row['distance_cm']))
    with (root/'data/summary.csv').open('w',newline='') as f:
        writer=csv.writer(f)
        writer.writerow(['sensor','experiment','condition','valid_count','invalid_count','mean_cm','half_range_cm'])
        for key,readings in groups.items():
            assert len(readings)==5, f'Incomplete trials for {key}'
            writer.writerow([*key,*summarize(key[0],readings)])
    assert len(groups)==32
    print('PASS: 160 trials, 32 conditions; invalid sentinels excluded from means')
if __name__=='__main__': main()

function plot_results
% Plot precomputed means with half-range bars; invalid sentinels have no mean.
root=fileparts(mfilename('fullpath'));
opts=detectImportOptions(fullfile(root,'data','summary.csv'),'TextType','string');
opts=setvartype(opts,'condition','string');
t=readtable(fullfile(root,'data','summary.csv'),opts);
f=figure('Visible','off','Position',[100 100 1300 600]);
cleanup=onCleanup(@()close(f));
experiments=["material" "incidence_deg" "offset_cm"];
titles=["Target material" "Incidence angle (degrees)" "Lateral offset (cm)"];
for k=1:3
 subplot(1,3,k);hold on;
 for sensor=["ToF" "Ultrasonic"]
  rows=t(t.experiment==experiments(k) & t.sensor==sensor,:);
  errorbar(1:height(rows),rows.mean_cm,rows.half_range_cm,'o-','DisplayName',sensor,'LineWidth',1.2);
 end
 xticks(1:height(rows));xticklabels(rows.condition);if k==1,xtickangle(60);end
 title(titles(k));ylabel('Mean distance (cm)');grid on;
end
legend('Location','northwest');sgtitle({'Rover sensor bench measurements: five trials per condition', ...
 'Bars: half range. ToF 6 cm offset and ultrasonic sponge: all five readings invalid, omitted.'});
exportgraphics(f,fullfile(root,'results.png'),'Resolution',180);
end

from pathlib import Path
import importlib.util
import unittest
ROOT = Path(__file__).resolve().parents[1]
class AnalysisTest(unittest.TestCase):
    def test_sentinels_are_failures_and_not_distances(self):
        self.assertTrue((ROOT/'analyze.py').exists(), 'Missing reproducible invalid-reading rejection')
        spec=importlib.util.spec_from_file_location('analysis', ROOT/'analyze.py')
        m=importlib.util.module_from_spec(spec);spec.loader.exec_module(m)
        self.assertEqual(m.summarize('ToF',[819,819,819,819,819]), (0,5,None,None))
        self.assertEqual(m.summarize('Ultrasonic',[-.02]*5), (0,5,None,None))
