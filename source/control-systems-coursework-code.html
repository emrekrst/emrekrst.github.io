# Control systems coursework

MATLAB and Simulink studies by Emre Karausta, prepared during Electrical and Electronic Engineering coursework at the University of Southampton. Six folders cover six coursework projects: two-cart dynamics, five-DOF body vibration, beam modes and mass tuning, nonlinear cart–pendulums, helicopter pitch control, and inverted-pendulum lead compensation. Beam analysis and tuning are kept together.

The reproducible entry point is `run_all.m`. `src/` retains the coursework equations and models; several original plotting scripts expect a manually created `out` variable and are included for provenance, not as the clean-start entry point. The runner calculates results directly, runs the six saved simulation models, and logs outputs without saving logging changes into them.

## Run

Requires MATLAB R2024b, Simulink, Control System Toolbox, Signal Processing Toolbox, Simscape and Simscape Multibody. Symbolic Math Toolbox is needed only to regenerate `pendulum_ode.m` using the original `Task_B.m` derivation.

```sh
python3 verify.py
```

`MATLAB_BIN` can specify another MATLAB executable. Close any already-open target model before running; the helper refuses preloaded targets to protect unsaved work. Unrelated open models are left intact. The wrapper uses a temporary working directory and preferences, a 600-second process timeout, and writes generated traces/cache to ignored `results/`. It runs the analytical/nonlinear regression tests and the positive/negative torque-bound tests, then all saved simulation models. Alternatively, add this folder to MATLAB's path and call `run_all(false)` for the analytical and nonlinear ODE results, or `run_all(true, artifact_dir)` for the full run.

## Release changes

- Added a clean-start runner, explicit output logging, full timeseries instead of mixing capped `tout` with longer workspace arrays, and numerical regression checks.
- Added the missing −6/+10 Nm saturation to the copied helicopter model. The original saved model had no torque limiter and commanded 20 Nm for a 0.5 rad step. Both ±0.5 rad commands now stay within bounds. Gains and plant parameters are unchanged.
- Retained all original mechanical constants, including the five-DOF model's unusually large shoe damping coefficient. Matrix linear solves in the runner avoid explicit inverses.
- Retained differences between historical results and current reproduction. The helicopter response, two beam error percentages, and exact nonlinear matching are not presented as reproduced CV numbers.

Read [VERIFICATION.md](VERIFICATION.md) for numerical results, claim status and suggested corrected descriptions. `evidence/` contains compact recorded results. No physical rig was operated. See [ATTRIBUTION.md](ATTRIBUTION.md) before publishing or relicensing these academic materials.

# Verification — 22 October 2026

## Commands and environment

From the release folder: `python3 verify.py` (exit 0). It starts `/Applications/MATLAB_R2024b.app/bin/matlab -batch` with `test_release; test_torque_limits; run_all(true, artifact_dir)`, using absolute addpaths, temporary cwd/preferences/TMPDIR, and a 600-second process timeout. All execution used copies. Compact actual output and numerical JSON are in `evidence/`.

MATLAB 24.2.0.2923080 (R2024b) Update 6 on macOS 15.7.3, Apple Silicon. Available and exercised: Simulink, Control System Toolbox, Signal Processing Toolbox, Simscape, Simscape Multibody, all version 24.2. Symbolic Math Toolbox 24.2 was installed; the existing generated ODE was used rather than regenerating it. No toolbox/license blocker occurred.

`test_release` passes numerical resonance, body-mode, Rayleigh, point-mass ratio, phase-margin, unstable-pole and nonlinear passivity checks. `test_torque_limits` passes both ±0.5 rad commands. Six physical/signal models execute: two-cart 10 s, each of three beams 10 s, nonlinear cart–pendulums 100 s, helicopter 10 s. Expected MATLAB warnings report instability when evaluating the motor-lag loop. Startup emits Java X11-package warnings; they did not prevent execution.

Beam frequency extraction uses positive displacement peaks after 5.1 s (free response after the force pulse), three-sample quadratic interpolation in actual simulation time, then reciprocal median peak spacing. Errors above are calculated from measured signals, not copied from the CV. Different cursor-based or spectral estimators may give different rounded errors; their historical settings were not retained.

The nonlinear ODE uses g=9.81 while the saved Simscape model uses 9.80665 m/s². A separate diagnostic using the saved model's gravity reduced angular differences to approximately 0.0033/0.0048 rad, but residual differences remained and that diagnostic did not meet a 0.001-unit comparison test. It was not used to overwrite the baseline results or claim exact matching.

## Defects and red/green evidence

Before the harness existed, the release lacked clean-start execution and original plotting scripts required manually generated `out` data. Initial checks failed; the release now runs without that base-workspace dependency. A first integration run also exposed a real logging mismatch: original `tout` was capped at 10,000 samples while nonlinear output arrays held 50,002 samples. The helper now captures individual full timeseries. Another initial logger attempted duplicate named branches; deduplicated logging now supports the turbojet package independently.

The helicopter behavioral regression failed with 20 Nm for a 0.5 rad command. Adding the single saturation block produced passing +0.5 and −0.5 rad tests. Original gains and dynamics were retained. The original model is unchanged outside this release; the baseline failure log is retained in compact form.

## Suggested precise CV wording

- Beam: “Validated simulated beam frequencies against analytical references; current reproducible extraction gives approximately 0.04% cantilever, 0.37% simply supported, and 0.35% against the half-frequency tuning target.” Retain historical numbers only if their original measurement method can be produced.
- Nonlinear: “Cross-compared MATLAB and Simscape responses over 100 seconds, aligned coordinate references and quantified peak differences of about 1.5 mm and 0.018 rad in the retained models.”
- Helicopter: “Implemented derivative-on-feedback PD control; the retained ideal model gives about 0.256 s settling time and 4.3% overshoot for a 0.25 rad command. Reproduced the loss of stability with 0.1 s motor lag.” Describe torque saturation as an added release correction unless historical evidence supports earlier enforcement. Report phase margins without an unqualified infinite gain-margin claim.

No physical validation, employer/university publication permission, or public licence was established by these tests. No originals were edited and no remote, commit, push or publication was performed.

A final independent review found that broad `bdclose('all')` cleanup could close unrelated unsaved models. A behavioral sentinel regression reproduced that failure. The broad cleanup was removed. The simulation helper now refuses already-loaded target models before mutation, with an actionable `release:ModelAlreadyLoaded` error. Final targeted MATLAB command `test_model_ownership; test_release; test_torque_limits` exited 0 after that lifecycle-only correction; it checks unrelated unsaved models on success/error and preserves a preloaded same-name target. The full six-model numerical run above preceded this lifecycle correction. See the retained red/green ownership logs.

function out = simulate_logged(model_file, stop_time, step_amplitude)
% Add logging only in memory. Never save over the supplied model.
[~,mdl]=fileparts(model_file);
if bdIsLoaded(mdl)
 error('release:ModelAlreadyLoaded','Close or save and close the already-open model %s before reproduction.',mdl);
end
load_system(model_file);
cleanup=onCleanup(@()close_system(mdl,0));
if nargin>2,set_param([mdl '/Step'],'After',num2str(step_amplitude));end
try,set_param(mdl,'SimMechanicsOpenEditorOnUpdate','off');catch,end
scopes=find_system(mdl,'SearchDepth',1,'BlockType','Scope');
for i=1:numel(scopes)
 ports=get_param(scopes{i},'PortHandles');
 for j=1:numel(ports.Inport)
  line=get_param(ports.Inport(j),'Line');if line<0,continue,end
  src=get_param(line,'SrcPortHandle');name=sprintf('release_scope_%d',i);
  if numel(ports.Inport)>1,name=sprintf('%s_%d',name,j);end
  block=[mdl '/' name];add_block('simulink/Sinks/To Workspace',block,'VariableName',name,'SaveFormat','Timeseries');
  ph=get_param(block,'PortHandles');add_line(mdl,src,ph.Inport,'autorouting','on');
 end
end
existing=find_system(mdl,'BlockType','ToWorkspace');
for k=1:numel(existing),set_param(existing{k},'SaveFormat','Timeseries','MaxDataPoints','inf');end
set_param(mdl,'LimitDataPoints','off');
set_param(mdl,'ReturnWorkspaceOutputs','on','MaxStep','0.002','RelTol','1e-7');
if nargin>1,set_param(mdl,'StopTime',num2str(stop_time));end
out=sim(mdl);
end

function test_model_ownership
% A reproduction must not close or modify someone else's open models.
root=fileparts(fileparts(mfilename('fullpath')));
sentinel='release_unsaved_sentinel';target='PI_D_controller';
assert(~bdIsLoaded(sentinel) && ~bdIsLoaded(target),'Close test model names before running ownership test');
new_system(sentinel);add_block('simulink/Sources/Constant',[sentinel '/unsaved_work']);
cleanup=onCleanup(@()close_owned({sentinel,target}));
run_all(false);
success_preserved=bdIsLoaded(sentinel);
% New unsaved model with the same name must be refused before it is touched.
new_system(target);add_block('simulink/Sources/Constant',[target '/unsaved_target']);
try
 simulate_logged(fullfile(root,'src','helicopter',[target '.slx']),0);
 refused=false;
catch err
 refused=strcmp(err.identifier,'release:ModelAlreadyLoaded');
end
target_preserved=bdIsLoaded(target) && getSimulinkBlockHandle([target '/unsaved_target'])>0;
% Missing-file failure must also leave the unrelated model open.
try,simulate_logged(fullfile(root,'not_a_model.slx'));catch,end
error_preserved=bdIsLoaded(sentinel);
assert(success_preserved && error_preserved,'Runner closed an unrelated unsaved model');
assert(refused && target_preserved,'Runner must refuse a preloaded target without changing or closing it');
fprintf('PASS: unrelated models survive success/error, preloaded targets are refused intact\n');
end
function close_owned(names)
for k=1:numel(names),if bdIsLoaded(names{k}),close_system(names{k},0);end,end
end
